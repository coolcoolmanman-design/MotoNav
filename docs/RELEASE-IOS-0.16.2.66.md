# iOS 0.16.2.66

配套固件 `7.12.10-ui.2-zelda40.9-musicA.72`。基线 0.16.2.65 / musicA.71。
本版为 **FO-219 实机反馈修正** 的配套包，核心修复在固件侧；App 侧只补一条生效范围说明。安卓端本版不改。
两份 release 保持 draft，不 publish。

## 变更

- `DeviceHomeViews.swift` 的动态背景设置区新增一行说明：
  「仅待机首页生效（中央=动画、非全屏表盘）；音乐页 / 导航页 / 全屏表盘自绘底色，不会显示动态背景。」
  起因是用户反馈「选择后都是黑色背景」——动态背景由固件 `bgSrc()` / `zbgRect()` 只在待机首页铺底，
  其他页面自绘底色，之前 UI 没有写清这个边界。
- 风格下拉框、预览圆屏、7 个选项与 `#BG` 下发协议均不变。

## 配合固件

- FW musicA.72 修了黑胶唱片页两处实机问题：歌名/歌手/时间胶囊重叠、唱片旋转 10fps 且 36 秒/圈卡顿
  （改为局部静态层缓存 + 24fps + 12 秒/圈），并给 `#BG` 加了无条件门控诊断日志。
- **必须同升 FW musicA.72** 才能看到上述修复；App 单独升级只有文案变化。
- 动态背景本身功能未改：排查黑背景时看固件开机日志的
  `[BG] ... active=.. custom=.. lp=.. buf=.. page=.. wait=..` 一行即可确认门控与当前页面。

## 建议实机验证

1. 侧载本 IPA + 刷 FW musicA.72，先在 App 里确认新说明文字显示正常、不挤占其他设置项。
2. 圆屏停在待机首页选「像素夜景」，确认图案出现；若仍为纯黑，抓开机日志按 `[BG]` 行定位 `active/custom/lp/buf`。
3. 音乐样式选「黑胶唱片」，确认四层文字分离、封面旋转顺滑。

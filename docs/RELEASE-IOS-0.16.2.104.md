# MotoNav iOS 0.16.2.104（通用固件 musicA.114）

## 修复
- 圆屏 WiFi 地图加速（FO-261）：内部 RAM 结构性腾退后热点可启动。
  - 固件将 6 个独立 tinfl 解压器合并为 1 个共享实例（省 ≈55KB 内部 RAM）；
  - 车道胶囊缓冲（42KB）与地图临时数组（32KB）改走 PSRAM；
  - BLE 连接态内部堆可用连续块从 ≈18KB 提升到 ≈70KB+，SoftAP init 不再 0x3001 失败。
- App 无代码改动；与 musicA.114 固件配套使用。

## 刷机
- 通用包内含 musicA.114 固件；已刷 0.8000 分区表 + 0x10000 app 者无需重复刷分区表。
- 验证：连接设备 → WiFi 加速开关 → 圆屏提示热点已开启（串口 `WIFI MAP softAP ok`）。

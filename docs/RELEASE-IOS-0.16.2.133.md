# iOS 0.16.2.133 — 新增「昼夜通透」地图样式（配套 musicA.148）

基线 0.16.2.131。**固件需要 musicA.147+**（样式 16 在 .147 首次加入，透视/字体特效在 .148 补齐）。

## 改了什么

### 1. 样式选择器新增 id 16「昼夜通透」
- `Settings.themeOrder`：`[1, 14, 15, 16, 0, 5, 11, 10, 12, 13]`，排在「矢量3D鸟瞰」后面，方便和 15 对比。
- `themeName(16) = "昼夜通透"`；
- `themeDesc(16) = "Tilt3D 透视鸟瞰 + 青蓝通透地图：深色渐变顶遮罩、白字软投影、金色路线、蓝色车标；日夜自动随光而变"`。
- 启动时读回 `map_theme` 的白名单同步加上 16，否则重启会掉回罪恶都市。

### 2. 让固件把 16 也当「楼块样式」
样式 16 在固件里走 `Tilt3D` 透视，楼块是**从栅格 16 色索引 4..7 的脚印挤出来的**，没有轮廓数据就只有一张斜的平面地皮。所以：

- `MapFeeder.buildingMode`：`t == 1 || t == 14 || t == 15 || t == 16`，样式 16 也会做高德建筑轮廓双截图、走楼块栅格回落；
- `Settings.syncBuildingContinuity()`：`#BC,1` 的判定同样放行 16，圆屏知道接下来收的栅格带楼块层。

其余（路口放大图、车道、`#ELV` 高架、路线进度）与 15 一致，没有协议改动。

## 兼容

| App | 固件 | 结果 |
|---|---|---|
| 0.16.2.133 | musicA.148+ | 完整效果（透视 + 楼块 + 软投影 + 顶遮罩 + 蓝色车标） |
| 0.16.2.133 | musicA.147 | 有透视，但数字/时间还是旧的硬阴影，没楼块 |
| 0.16.2.133 | ≤ musicA.146 | 固件没有 `ST_DAYNIGHT_GLASS`，`#t,16` 会被忽略 → 停在原样式 |
| 0.16.2.131 及更早 | 任意 | 选择器里没有 16，只能用 15 |

# MotoNav iOS 0.15.25-tpms

通用圆屏固件配套 · 基于 `0.15.24-tpms`：导航 Tab 合并路线规划入口，独立规划页「自行车」改「非机动车」。

**本包为 Draft / 脱敏侧载包，供自测；未对 main 合入、不推上游。无公开 PR。**

## 本版内容

### 导航 Tab · 路线按钮（P0）
- 去掉巡航与去哪儿之间的两颗独立胶囊：「摩托车路线规划」「自行车路线规划」。
- 在「去哪儿」内，与「粘贴高德分享的路线」**同一行、右侧**增加一颗按钮，标题精确为 **摩托车/非机动车路线规划**。
- 两颗按钮 **等宽等高**（`HStack` 各 `maxWidth: .infinity` + 相同 `minHeight`），均为单层胶囊，无嵌套描边。

### 独立规划页文案
- 分段 / 导航标题 / 规划 CTA / 页脚等用户可见「自行车」一律改为「非机动车」；摩托车文案不变。
- `IndependentPlannerView` 行为不变（仍走原摩托车网页规划 / SDK 骑行规划路径）；仅展示字符串。

### 继承 0.15.24（未改）
- 连接弹层圆屏预览正立（mockup C）；圆屏毛边 / hero 透视；关于副标题「信息和调试」。

## 固件

请同时刷入 **`7.12.11-opt.9`**。勿与 stopwatch / flag 协议包交叉。

- 高德 Key **不在包内**。

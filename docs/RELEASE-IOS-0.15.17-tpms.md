# MotoNav iOS 0.15.17-tpms

通用圆屏固件 **7.12.11-opt.4** 配套 · 基于 `0.15.16-tpms` 叠 **整幅底图空白（仅导航线）修正**。

**本包为 Draft / 脱敏侧载包，供自测；未对 main 合入、不推上游。**

## 修正诊断（相对 0.15.16）

实机照片不是「开出上一块瓦片窗口」的局部空白，而是 **basemap 全幅落地色（罪恶都市暖沙）+ 矢量导航线仍在**。主因：道路分类把 `bgLum` 写死为 248，只认近白路（lum≥254）；高速/高德灰路面被整块标成陆地 → 圆屏只剩主题陆地填色。

## 本版内容

- **道路分类**：用实测 `backgroundLum`；补中灰高速路面判定（低饱和、与底色差 ≥22）。
- **空底图拒绝**：材料像素过少的包不发出 / 不覆盖已有密底图（`base-empty-mask` / `packet-empty-mask`）。
- **高速明文 RLE**：≥80 km/h 直接 plain RLE（不再先发 DFL 再等 NACK），路线仍走 type 2。
- 保留 0.15.16 的地图优先队列、迟到包保留、DXR 重叠门槛。

## 固件

- **请同时刷入** `7.12.11-opt.4`（近空 type-3 在已有密底图时 NACK，避免空包顶掉好图）。

## 安装

- IPA：`MotoNav-0.15.17-tpms-unsigned.ipa`（unsigned 侧载）；同 Bundle ID 覆盖安装。
- 高德 Key **不在包内**。

## 自测建议

刷 `7.12.11-opt.4` → 装本 IPA → 罪恶都市主题 → 模拟导航 120 km/h。底图应持续有道路，而不只是紫线+HUD。

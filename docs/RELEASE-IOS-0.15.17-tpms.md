# MotoNav iOS 0.15.17-tpms

通用圆屏固件 **7.12.11-opt.4** 配套 · 基于 `0.15.16-tpms` 叠 **整幅底图空白修正（PR #9）** + **IA/UI 冷淡科技二级菜单与设备/轨迹视觉（本包）**。

**本包为 Draft / 脱敏侧载包，供自测；未对 main 合入、不推上游。**

## 修正诊断（相对 0.15.16 · basemap）

实机照片不是「开出上一块瓦片窗口」的局部空白，而是 **basemap 全幅落地色 + 矢量导航线仍在**。主因：道路分类把 `bgLum` 写死为 248，只认近白路；高速/高德灰路面被整块标成陆地。

- **道路分类**：用实测 `backgroundLum`；补中灰高速路面判定。
- **空底图拒绝**：材料像素过少的包不发出 / 不覆盖已有密底图。
- **高速明文 RLE**：≥80 km/h 直接 plain RLE；保留 0.15.16 地图优先队列与迟到包策略。

## IA / UI（本包）

- **四 Tab**：导航 / 轨迹记录 / 设备 / 我的（功能保留，过载项进二级）。
- **我的**：通用 · 圆屏与连接 · 胎压 · 地图与导航 · 关于（drill-in，少滚动）。
- **设备**：加大圆屏连接卡（机身图 + 椭圆投影）+ 显示/地图/系统入口；胎压卡带轮胎图（bar 展示）。
- **轨迹**：每条骑行 MapKit 轨迹缩略 + 详情全幅地图（基于已有 fixes，无需高德 Key）。
- **连接动画**：拉丝金属贴图、高精屏贴、椭圆地面阴影（非方影）、SF Blue 进度条；文案「正在连接圆屏…」。

## 自测建议

1. 刷 `7.12.11-opt.4` → 装本 IPA → 罪恶都市主题 → 模拟导航 120 km/h：底图应持续有道路。
2. 设备 Tab：连接卡机身图与椭圆影、胎压轮胎图、显示/地图/系统二级。
3. 我的：顶层分组少滚动，圆屏与连接 / TPMS 功能仍在。
4. 轨迹：有历史记录时列表缩略与详情地图；无记录时可「开始记录」手动采点。
5. 点连接：动画阴影为椭圆、文案为「正在连接圆屏…」。

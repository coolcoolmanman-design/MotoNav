# MotoNav iOS 0.16.2.24

## 新增：路口放大图下发到圆屏

- 接上高德 `driveManager:showCrossImage:` 的位图，处理后走 bulk `type 9` 发给圆屏
  （固件 musicA.26 起支持），圆屏整页显示路口大图。
- **深色化**：灰阶反相（白底→近黑、黑字→浅灰），彩色保留色相只提亮。判定「灰」用绝对色差
  `chroma < 26`，否则深色路名会被误判成彩色、提亮后糊成一片。
- **量化**：固定 16 色调色板（10 级灰阶 + 蓝/红/黄/绿/紫），nibble RLE 打包，实测 3~15KB。
- 缩放固定 380×243（25:16），与 466 圆屏上卡片的显示尺寸一一对应，不裁切不变形。
- 同一个路口重复推送会按像素哈希去重，不会反复占带宽。
- `driveManagerHideCrossImage:` → 发 `#CXH`，圆屏退回小地图。

## 设置

「圆屏 Tab → 圆屏显示」新增 **路口放大图** 开关（默认开），下发 `#CX,<0|1>`，
圆屏存 NVS 记住；连接时 `pushAll` 会重发一次。

## 其它

- 调试卡里会显示处理结论（尺寸/比例/透明/PNG 体积，以及是否成功下发）。
- 需要圆屏固件 musicA.26 或更新版；旧固件会忽略 type 9，App 侧检测不到 `CAP,CXG,1` 时也不会发。

# MotoNav iOS v0.15.9

## 本构建

- **新 App 图标（A+C 融合）**：圆屏玻璃表圈 + 摩托侧影 + 透视公路与前进导航箭头；小尺寸保留侧影清晰度，同时强化圆屏 HUD / 导航语义。
- **iOS 18 白夜图标**：Asset Catalog 提供 Light（Any）/ Dark / Tinted 三套，主屏外观自动或手动浅深色时可切换。
- **沿用 0.15.8**：自动白夜界面、四栏信息架构（出行 / 收藏 / 圆屏 / 我的）、Apple Music 式液态玻璃底栏、Duo 三形态；特别版客户端仍停编。

## 安装

- 下载 `MotoNav-0.15.9-unsigned.ipa` 侧载安装（不覆盖既有 `ios-v0.15.8` 发布标签）。
- 固件按既有通用圆屏配套即可。

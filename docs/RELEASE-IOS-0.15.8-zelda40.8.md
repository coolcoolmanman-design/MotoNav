# MotoNav iOS v0.15.8-zelda40.8（塞尔达40周年特别版修订 8）

## 本版一起修三件事

1. **选项卡不再纯白**：卡片内分段改凹陷轨道 + 粉强调选中，去掉白玻璃压层。
2. **导航 Tab 恢复液态玻璃实时变化**：重新启用 iOS 26 `glassEffect`（内容滚动时实时折射）；禁止 0.14~0.55 白洗；`light` 仅极淡 tint（0.06）。
3. **信息架构迁移**：底部 5 Tab → 4 Tab（出行 / 收藏 / 圆屏 / 我的），功能不删；Duo 底栏 / 外屏竖栏 / 展开双栏保留。

### Tab 迁入

| Tab | 内容 |
| --- | --- |
| 出行 | 去哪儿 / 分享导入 / 巡航 / 摩托·自行车 / 开导 |
| 收藏 | 常用目的地 / 最近去过 / 骑行轨迹 |
| 圆屏 | 连接状态 / 显示策略 / 亮度方向刷新媒体开机动画 |
| 我的 | 语音 / Key·天气 / Duo 摆位 / 调试 |

### 验证

- 底部导航条：通透液态玻璃，滚动内容时折射跟手，不是纯白块。
- 设置内分段：浅凹陷底，不是白板。
- Duo 合盖竖栏 4 项；展开出行页左右分栏。

## 安装

- 下载 `MotoNav-0.15.8-zelda40.8-unsigned.ipa` 侧载。
- 固件无需变动。

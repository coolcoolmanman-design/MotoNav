# MotoNav iOS 0.16.2.11-tpms (build 26)

在 0.16.2.10 基础上：

## 新增：组件槽自定义（二期C）

「圆屏设置」新增「组件槽自定义」区：待机页拆成背景 + 组件槽，四个槽（时间 / 电量 / 连接态 / 气压占位）
各自可调显隐与颜色（九档：自动/白/金/青/绿/橙/红/粉/灰）。改动立即下发 `#FC`（约 30 字节），
圆屏秒切；连接时自动同步，配置存圆屏 NVS 断电不丢。气压占位槽显示手机透传的蓝牙气嘴前/后 kPa，
开启时替换待机页天气显示。

## 调整

- 导航条样式回归 0.15.10：悬浮液态玻璃胶囊 + 选中态软色圆晕（替换 0.16.2.7 起的液滴透镜样式）。

## 配套固件

7.12.10-ui.2-zelda40.9-musicA.8（#FC 组件槽 + 顶部电量数字内嵌电池图标）。

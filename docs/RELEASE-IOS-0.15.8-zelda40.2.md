# MotoNav iOS v0.15.8-zelda40.2（塞尔达40周年特别版修订 2）

## 改动

1. **选项卡底纹改白夜透明**：iOS 26 液态玻璃不响应深色模式环境覆盖，底部导航条与折叠屏右侧竖栏改为显式白色 tint 玻璃，固定深色背景下全天呈现白夜模式的透明观感（内容文字/图标同步按浅色渲染保证对比度）。
2. **断开即时离线**：点「断开」先向圆屏发送 `#OFF` 告别指令再取消连接，圆屏立即切离线场景，不再因系统级 HID 自动重连而残留 ready。

## 安装

- 下载 `MotoNav-0.15.8-zelda40.2-unsigned.ipa` 侧载安装（iLoader / AltStore 等）。
- 建议与固件 v7.12.10-ui.2-zelda40.2 配套使用。

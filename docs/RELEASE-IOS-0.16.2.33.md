# MotoNav iOS 0.16.2.33（build 43）

配套固件：**musicA.37**（圆屏，App 与固件必须一起升级）

把已确认的两组设置效果图落成正式功能：**预设动态背景** 与 **六槽改造 / 时间样式**。
**开机动画下拉框原样保留**（19 个品牌 → `#BOOT` 一行没动），新增下拉框全部沿用同款纯文字菜单，菜单与设计稿里都不放缩略图。

## 一、圆屏设置 → 待机壁纸 → 预设动态背景

`DeviceBackgroundCard` 内新增子区（和「开机动画」同款菜单式下拉框）：

- 「预设动态背景」总开关 + 「风格」下拉 6 项：现有静态 / 呼吸金纹 / 流动极光（默认）/ 星尘粒子 / 斜向光扫 / 同心涟漪。
- 「漂移速度」分段控件：慢 ×1.0 / 标准 ×1.8（默认）/ 快 ×2.6，只缩放时间不改幅度。
- 「昼夜随时间自动切换」开关 + 日出日落状态行。**复用已有 `Settings.startDayNight()`**（每分钟按当地日出日落 → `paletteNight` → `#n`），动态背景读同一个昼夜状态，不新增定时器。关闭后锁定白天配色。
- **自定义壁纸 > 动态背景**：上传成功后动态帧暂停但保留已选风格（控件仍可改，不用重选），点「恢复默认」清掉图片后自动续上。圆屏侧靠 `bgCustomOn` 自动判断，App 不用额外发暂停命令。
- **右上圆屏预览**：复用现有 `backgroundPreview`（84px 圆 + 92px 描边）。没上传图片时显示该风格当前帧（新增 `DynamicBgDial`，0.2s 一拍缓慢漂移，昼夜跟随 `paletteNight`）；上传后同一位置改显自定义图片。

下发 `#BG,<on>,<style>,<speed>,<auto>`，圆屏存 NVS 并回执 `BG,...`；`pushAll()` 连上圆屏时自动同步。

## 二、圆屏设置 → 六槽表盘

- 「时间槽」→ **上方槽**（Picker）：时间 / 速度 / 实时G值 / 胎压 / 天气；非时间功能在圆屏上放大显示。
- 「中央动画」→ **中央槽**（Picker）：中央动画 / 时间 / 全屏指针表盘。
- 新增「时间样式」下拉 9 项纯文字：现有像素数字 / 石英极简大数字 / G-Shock 七段电子 / 潮流纵向排列 / LED 点阵 / 石英三针 / 包豪斯几何 / 月相机械 / 数字指针混合。中央槽不是时间时置灰。
- 中央槽选「全屏指针表盘」时多出「全屏数据槽」分段控件：A 纯净（推荐）/ B 外环信息带。
- 两个槽同时显示时间时给一条橙色提示，建议上方槽改选别的功能。
- **中央动画载具**（`#FV`）选项原样保留，中央槽不是动画时只置灰、不删除。
- 规则说明写进页面：上方槽选「时间」才显示大时钟与每秒红点；任一槽有时间就显示外圈 60 格刻度；全屏表盘进入导航自动让位。

下发 `#FC3,<top>,<center>,<style>,<ab>`。**旧 `#FC2` 格式一字不改**，只是 `faceCfgMask` 的 bit0 改成由「上方槽 = 时间」推导（老固件收到后行为正确），bit3 恒 1。`pushAll()` 里 `#FC2 → #FC3 → #FV → #BG` 顺序同步；`MotoNavApp.swift` 新增 `FC3` / `BG` 两条回执分发。

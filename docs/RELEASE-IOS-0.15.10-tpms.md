# MotoNav iOS v0.15.10-tpms

## 本构建（胎压监测 + 连接动画）

在 0.15.10 基础上新增两个功能：

### 1. 圆屏胎压卡片（圆屏 Tab）

- 手机被动扫描蓝牙胎压气嘴的广播包（LyTPMS 协议），解码出胎压（kPa）、温度（°C）、气嘴电量（%）。
- 读数经 BLE 实时转发到圆屏：圆屏胎压页 LIVE 显示，前/后轮各含压力、温度、电量徽标。
- 前后轮自动配对：首次扫描到两颗气嘴时按发现顺序绑定（第 1 颗→前轮、第 2 颗→后轮），可在卡片里清空重新配对。
- 气嘴静止时静默属正常现象：卡片与圆屏保持最后一次读数，直到压力再次变化或气嘴重新上电。
- 卡片内可设低压报警（kPa）和高温报警（°C），越限后圆屏侧标红提醒。
- 扫描带防限流保护（心跳计数 + 定期重启扫描），长时间运行不会失聪。
- 「发送测试帧」可注入一组样本读数，用于验证手机→圆屏链路。

### 2. AirPods 式连接动画

- 启动自动连接、圆屏页手动点「连接」都会弹出 3D 圆盘动画：铝合金圆盘 360° 旋转后定格，显示连接状态与圆屏电量。
- 圆盘正面屏贴内容方向已按要求旋转 180°。
- 设置里可重置「首次配对」标记，重新体验首次动画。
- 注：动画中的电量读数需要圆屏固件支持 `V` 电量回报，否则显示「—」。

## 兼容性

- 基于 `ios-v0.15.10`，功能完全一致，另含上述两项新增。
- 胎压协议与安卓端 TPMS 版本互通（同一套解码与 `#TP` 转发格式）。
- `CFBundleShortVersionString` 保持纯数字 0.15.10，可覆盖升级同 Bundle ID 的旧版。

## 安装

- 下载 `MotoNav-0.15.10-tpms-unsigned.ipa` 侧载安装（同账号同 Bundle ID，可覆盖 0.15.10）。
- 不覆盖 `ios-v0.15.10` 及更早标签。

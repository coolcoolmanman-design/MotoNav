# MotoNav iOS 0.16.2.9-tpms（表盘选择）

## 新增：圆屏待机页可换表盘

- 「圆屏设置」页第 2 项新增**表盘选择**（第 1 项仍为开机动画）：默认 / 塞尔达绿 / 极简黑 / 赛博霓虹 / 机械 / 运动橙。
- 选择后下发 `#FACE,<id>`，圆屏存 NVS 并回 `FACE,<id>` 确认，状态提示"已保存，下次待机生效"；切换后待机页立即换背景。
- 连接圆屏时自动同步当前表盘（`pushAll`）；断电重启沿用。

## 配套固件

- 需搭配固件 **7.12.10-ui.2-zelda40.9-musicA.7**（draft release `firmware-v7.12.10-ui.2-zelda40.9-musicA.7`，基于昨天 musicA.5 基线 + #FACE 渲染）。旧固件只保存选择，画面暂不变化。

## 其他

- 继承 0.16.2.6-tpms 全部能力（TPMS、蓝牙媒体按键、#TIME 对时等）。

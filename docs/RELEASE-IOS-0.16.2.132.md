# iOS 0.16.2.132 — 导航提示文字改完整句式

基线 0.16.2.131（含路口放大图配色修复 + 高架 `#ELV` 上报 + 首页清晰设备图）。**需配固件 musicA.145** 才能看到新布局；只装 App 不刷固件，文案会变成完整句式但显示位置仍是旧版底部大箭头样式。

## 改了什么

3D 鸟瞰样式（样式15）在固件 musicA.145 里把导航提示文字从底部挪到中部。中部空间窄，旧的下发短句信息量不够——旧版 `updateTexts()` 下发的是：

- 转弯时：`进入 <路名>`（不带转向动作）
- 直行时：`沿 <当前路> 直行`

新版把转向动作并入下发的 slot0 文字位图：

| dir | 文案 |
|---|---|
| R | 右转进入`<下一条路>` |
| L | 左转进入`<下一条路>` |
| SR | 右前方进入`<下一条路>` |
| SL | 左前方进入`<下一条路>` |
| U | 掉头进入`<下一条路>` |
| S | 沿`<当前路>`直行 |
| A | 前方为目的地 |

例如「右转进入中山门大街」，与参考图一致。

## 配对

- 固件 musicA.145：3D 鸟瞰 HUD 重排（箭头+206m 上移到地平线以上、提示文字中部、车速+里程底部、电量左下）
- 本版 App 只改文案逻辑，不碰路口图配色 / BLE / 底图等其它模块

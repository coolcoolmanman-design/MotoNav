# iOS 0.16.2.88 · musicA.99

移除已废弃的「WiFi 地图加速」入口，与固件 musicA.99 对齐。底图收发全程走 BLE 稳定通道。Draft-only（夜测/自测用）。

## 本版变更

- **隐藏「WiFi 地图加速（试验）」开关**：设置页不再显示该入口。对应固件能力已从 musicA.99 起移除（BLE 与 WiFi 驱动在本芯片 320KB 内部 RAM 无法共存，`esp_wifi_init` 因内存不足失败）。
- **App 侧彻底禁用 WiFi 路径**：不再发送 `#WIFI,1/#WIFI,0/#WIFI?` 命令、不再尝试 NEHotspot 加入与 TCP:7443 传输；所有底图整包统一走 BLE（与 .94 之前的稳定通道一致）。
- 地图、导航、封面流、动态背景等功能不变。

## 版本

- iOS `0.16.2.88` · build `97`
- FW `7.12.10-ui.2-zelda40.9-musicA.99`

## 配套固件

- 固件 **musicA.99**（去 WiFi 功能版）；刷机仍遵循：先写 `0x8000` 分区表，再写 `0x10000` app，切勿使用 `full_0x0.bin`（会擦 NVS）。

# iOS 0.16.2.19（build 34）

musicA.18 实测反馈配套调整：

## 变更
1. **设置页删除「表盘选择」**（塞尔达绿 / 阳光 / 加州等主题列表移除），固件恒定默认表盘。
2. **吧唧文字滚动字体加宽**：文字渲染横向矢量拉伸 1.35 倍（笔画同步变宽、不糊）。
3. **App 内版本号修复**：`APP_VERSION` 硬编码自 0.16.2.13 后未跟随 bump，现改为随版本同步维护（本版起显示 iOS v0.16.2.19）。
4. 其余（六槽自定义 / 背景上传裁切 / 载具三选一 / 主题包）沿用 0.16.2.18。

## 安装
unsigned ipa，照常 iLoader 侧载。需配合固件 musicA.19。

# MotoNav iOS v0.15.8-zelda40.6（塞尔达40周年特别版修订 6）

## 这一版：把被去掉的液态玻璃找回来，选项卡改透明

zelda40.4 为了把深色选项卡强行变白，把原生 `glassEffect`（液态玻璃）整个换成了
`ultraThinMaterial + 白色 0.48 压层` 的纯白平板——折射/高光那种「液态」质感从这一步起就没了；
zelda40.5 又整 App 强制浅色，于是看到的是「纯白平板」而非玻璃。

现在 App 已强制浅色、界面背后是亮内容，原生玻璃采样到的就是亮色 → 正好能做出**透明**毛玻璃。
本版恢复玻璃质感，并让选项卡从死白变透明。

### 具体改动

1. `AppTheme.liquidGlass`：zelda40.4 的「纯白平板」分支（light）作废。
   - **iOS 26+ 重新走原生 `glassEffect`**：透明液态玻璃，折射背后亮内容（浅色背景下即白天透玻璃），
     底部导航条 / 右侧竖栏 / 所有按钮芯片的液态质感复原。
   - **旧系统（<iOS 26）降级**：`ultraThinMaterial` 透明毛玻璃，仅叠极淡白（0.18）保证浮起感，不再塞死白。
2. `MotoNavApp` 分段选择器外观（`UISegmentedControl.appearance()`）：背景由 `white:0.94 alpha:1` 死白
   改为半透明白（`alpha:0.28`，选中项 `alpha:0.62`）——选项卡变**透明**而非纯白。
   - 说明：UISegmentedControl 本身不支持真正的背景模糊，这里是「透明」观感；若想要真正的毛玻璃模糊质感，
     可后续把设置页的 `.segmented` 换成自定义 `GlassSegmented`（复用 `liquidGlass`，iOS 26 即原生液态玻璃）。

### 验证（在你 Mac 上构建后确认）

- 底部导航条：iOS 26 上应看到通透的液态玻璃（能透出背后内容 + 高光折射）；旧系统为透明毛玻璃。
- 选项卡（设置页 刷新速度 / 预判 / 走过的路线 / 夜间配色等）：不再死白，呈半透明浅色。

## 安装

- 下载 `MotoNav-0.15.8-zelda40.6-unsigned.ipa` 侧载安装。
- 固件无需变动（配套 v7.12.10-ui.2-zelda40.3 即可）。

# MotoNav iOS 0.15.7

## G 值口径修正
- 手机 `#G` 推送改为**动态 G**：只取 CoreMotion 的 userAcceleration（已去除重力），静止≈0.00、晃动/颠簸才变化；0.05g 死区滤噪声。修复"手机不动也显示 0.99"（旧口径含重力，静止=1g）。
- 圆屏板载 IMU（固件 v7.12.9-ui.11 起）同步改为去重力口径，两端一致。
- G 页数据优先级不变：手机 #G（PHONE）> 板载 IMU（SENSOR）> 0（NONE）。

## 继承
- 0.15.6：CoreMotion 采样在后台队列（滑动卡顿修复）。
- 0.15.5：`TIME?` 首连对时应答。

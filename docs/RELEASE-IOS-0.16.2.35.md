# MotoNav iOS 0.16.2.35（build 45）

配套固件：**musicA.39**（圆屏，App 与固件必须一起升级）

在 0.16.2.34 / musicA.38 音乐样式上修两处实测问题。**App 设置项与 `#MS` 协议不变**；本版主要是固件布局修复，IPA 跟版配对。

## 修复

1. **封面轮播**：左/中/右不再是同一张封面原样。左邻优先上一首历史封面（换歌时固件缓存），否则冷青偏色偏裁；右邻 AMS 无下一首封面时用暖洋红偏色偏裁或几何占位。中封仍为当前原色 + 橙色方沿进度。
2. **柔光立体**：歌名 + 作者挪到底栏 prev/next 中间空隙；歌词仍在封面下方中部。

# MotoNav iOS 0.16.2.14（自适应旋转 + 行程卡片迁移 + 连接动画去影 + 胎压重配对）

## 新增 / 调整

### 1. 自适应旋转（圆屏设置 → 圆屏方向）
- 圆屏根据六轴 IMU 重力感应自动保持画面正立，无论设备如何旋转，圆屏始终正向显示。
- 「圆屏设置 → 圆屏方向」新增「自适应旋转（屏幕始终正向）」开关；开启后手动圆屏方向被忽略，关闭则回到手动角度。
- 需搭配固件 **7.12.10-ui.2-zelda40.9-musicA.14**（新增 `#AR,` 指令同步开关状态）。

### 2. 行程卡片迁移到导航 tab
- 「常用目的地」与「最近去过」两张卡片从「行程」tab 底部移出，固定置于「导航」 tab 底部，常驻不消失。

### 3. 设备连接动画去影
- 彻底移除连接圆屏时 3D 模型的椭圆地面投影。

### 4. 胎压重配对弹出框
- 圆盘 tab「胎压监测」的「重新配对」按钮点击后弹出扫描列表，逐个气嘴可指定为前轮 / 后轮，避免前后轮混淆。

## 配套固件
- 固件 **7.12.10-ui.2-zelda40.9-musicA.14**（draft release `firmware-v7.12.10-ui.2-zelda40.9-musicA.14`）。

## 其他
- 继承 0.16.2.13 全部能力（TPMS、蓝牙媒体按键、#TIME 对时、塞尔达 40 周年开机/待机主题等）。
- 本发布为 draft，仅供自测 / 夜间刷机；iOS 需经 iLoader 侧载，固件刷入 0x10000。

# MotoNav iOS v0.15.10

## 本构建（滑动流畅度测试版）

在 0.15.9（A+C 昼夜图标）基础上优化主界面上下滑动卡顿：

- **只挂载当前 Tab**：不再四页保活，减轻滚动时的视图评估。
- **列表按钮改实色胶囊**：滚动区内不再对背后做液态玻璃实时采样；底栏仍保留液态玻璃（去掉 interactive 跟手态以减负）。
- **降频刷新**：BLE 调试计数批量更新；导航 UI 字段值不变不发；导航中横幅独立观察。
- **其它**：缓存中文语音列表；选路线预览地图关闭定位蓝点动画。

功能与 0.15.9 一致。请重点试：首页 / 收藏 / 圆屏 / 我的 上下滑、导航中返回主界面再滑、连着圆屏时滑动。

## 安装

- 下载 `MotoNav-0.15.10-unsigned.ipa` 侧载覆盖安装（同账号同 Bundle ID）。
- 不覆盖 `ios-v0.15.9` / `ios-v0.15.8` 标签。

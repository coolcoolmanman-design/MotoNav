# iOS 0.16.2.89 · musicA.99

在无 WiFi SoftAP 地图加速的基线（0.16.2.88 / musicA.99）上，重新开放可选的**天地图**圆屏底图路径，便于与高德 A/B。Draft-only（夜测/自测用）。

## 本版变更

- **地图来源可选**：圆屏设置 → 小地图 →「高德 / 天地图」分段控件。
  - **高德**（默认）：原 SDK 截图 → RLE → BLE（建筑轮廓仍仅高德+罪恶都市）。
  - **天地图**：HTTP `vec_w` 瓦片 → 同套 encode/BLE；**不**恢复 SoftAP / `#WIFI`。
- **Key**：天地图 Key 仍只存本机 `key_tdt`（Key 设置）；未填时取图明确失败「没填天地图 key」。仓库/Release 笔记不写真实 Key。
- **卫星图风格（10）**：继续走天地图 `img_w`（与来源无关）。
- **锁屏**：天地图 HTTP 取图在渲染暂停时不取消在途任务（与卫星图同类）；BLE 投递限制不变——见可行性简报，勿期待单靠换源消灭锁屏空白。

## 版本

- iOS `0.16.2.89` · build `98`
- 配套固件仍为 `7.12.10-ui.2-zelda40.9-musicA.99`（本包未改固件；可继续刷基线 FW Draft）

## 自测要点

1. 安装 IPA，填高德 Key；测天地图前再填天地图服务端 Key。
2. 圆屏设置 → 小地图 → 选 **天地图**；导航前台看圆屏底图是否换源（状态行可见「天地图 vec_w」）。
3. 切回 **高德** 对比。
4. 勿寻找「WiFi 地图加速」——该入口已隐藏且固件已移除。

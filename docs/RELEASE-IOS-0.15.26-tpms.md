# MotoNav iOS 0.15.26-tpms

通用圆屏固件配套 · 基于 `0.15.25-tpms`：导航 HUD 半透明 + 车头向上 + 光柱/回跟车；独立规划非机动车途经点；我的 Tab「语音」。

**本包为 Draft / 脱敏侧载包，供自测；未对 main 合入、不推上游。无公开 PR。**

## 本版内容

### 独立规划 · 非机动车途经点
- 「摩托车/非机动车路线规划」在 **非机动车** 分段恢复 **添加途经点**（控件与位置与摩托车页一致，最多 3 个）。
- 骑行 Search API 无原生 waypoints：按「起点→途经→…→终点」分段算路后拼接。

### 导航 / 模拟导航 HUD
- 底部控制行与「长按 退出导航」改回 **毛玻璃半透明**（冷淡科技，非实心白/灰）。
- 默认 **车头向上**（`trackingMode = carNorth`），禁止 SDK 在普通态擅自切正北。
- 路况 **光柱** 在捏合缩放 / 切显示模式后强制保持 `showTrafficBar`。
- 手动拖/缩放后约 **7 秒** 自动回锁车跟车（`autoSwitchShowModeToCarPositionLocked`；独立导航同超时回跟随 + 车头向上）。

### 我的 Tab
- 用户可见「导航语音」改为 **「语音」**（内部 `voice` key 不变）。

### 继承 0.15.25（未改）
- 去哪儿同行等宽：粘贴高德分享 | 摩托车/非机动车路线规划；规划页「非机动车」文案。

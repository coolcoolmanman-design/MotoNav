# MotoNav iOS 0.15.33-tpms

通用圆屏固件配套 · 基于 `0.15.32-tpms`：连接动画磨砂银外壳、圆屏卡标题/位姿微调、轨迹不记模拟导航。

**本包为 Draft / 脱敏侧载包，供自测；未对 main 合入、不推上游。无公开 PR。**

## 本版内容

### UI · 连接动画磨砂银壳
- 外壳改为 **磨砂银**（高粗糙度 PBR + 漫射噪点贴图），弱化亮面镜面
- 右侧 **扬声器 5 孔** + **上下实体键**
- 边缘圆角贴近实物（圆柱 + 环面 fillet）
- 地面投影改为中心实、边缘高斯衰减的软椭圆；去掉中空圆环伪影
- 屏贴保持 mockup C 正立（上 200 m / 下 28 km/h）

### UI · 圆屏「导航屏」卡
- 标题「导航屏」与「胎压监测」同主色、同字号字重
- 「连接 / 断开」略左；设备图 **仅右移**（`DevicePuckHero` 位图未改）
- 保留 0.15.32 b7：无「圆屏导航」；电量 / 连接 / CTA 同行

### 轨迹
- **模拟导航**（高德模拟 + 网页摩托车/非机动车模拟）不写入轨迹历史；会话级录音闸门 + 模式名拦截

### 继承 0.15.32
- 导航顶栏「导航」；路线预览起点蓝钉；map-blank 0.15.31 线

### 固件

请继续配对 **`7.12.11-opt.10`**（Release 标题里的 bundled 版本号可能仍显示仓库 `firmware/RELEASE_VERSION`）。

## 安装

- IPA：`MotoNav-0.15.33-tpms-unsigned.ipa`（unsigned 侧载）；同 Bundle ID 覆盖安装。
- 高德 Key **不在包内**。

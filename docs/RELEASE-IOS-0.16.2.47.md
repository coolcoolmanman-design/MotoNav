## 2. 电量管理

入口：**我的 → 通用 → 电量管理**

- 省电模式：降亮上限 + 关动态背景 + **中央动画冻帧**
- ≤10% 自动开启；**插电/充电自动退出**
- 近几小时电量折线（连接期采样，示意级）
- 低电 **App 内横幅**（非系统推送）
- 电池供电短按息屏：默认关，高级可开（`#PBO`）
- 电池健康 / 优化充电：灰显「当前硬件不支持」

协议：`#LP` / `#LPA` / `#PBO`；回执 `LP` / `LPA` / `PBO`。

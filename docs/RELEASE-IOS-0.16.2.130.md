# iOS 0.16.2.130 — 高架/桥梁悬浮（#ELV）

基线 0.16.2.129。**必须配对固件 musicA.142+**（旧固件不认 `#ELV`，只会当地面画）。

## 改了什么
- `NaviBridge` 新增高架判定：每次导航信息回调读当前 link 的路名
  - 含「高架 / 立交 / 跨线 / 大桥」→ 发 `#ELV,1`（圆屏抬高 14px）
  - 含「匝道 / 桥」→ 发 `#ELV,2`（抬高 8px）
  - 其它 → `#ELV,0`（回到地面）
- 只在状态变化时发一条，不占带宽；退出导航 / 到达 / 重规划时复位为 0。

## 圆屏表现（需固件 musicA.142+）
样式 15「矢量3D鸟瞰」下：车头箭头和导航蓝线抬到桥面高度，桥体正下方画深灰落地投影，
桥面铺一条比蓝线宽的浅灰带 —— 视觉上就是「开在高架上」。平地时完全无变化。

## 兼容
- 不升级固件：iOS 完全正常，只是圆屏没有悬浮效果。
- 不升级 iOS：固件收不到 `#ELV`，等价于 0，行为与 .141 相同。

# MotoNav iOS 0.16.2.106（配套固件 musicA.118）

## 修复
- 选择「高德原版」时不再因底图包超过 480KB 而整块空白：先把 16 色原版调色板逐级降到 12/10/8/6/5/4 色；仍过大时退回同一张高德截图的普通分类底图。
- 原版样式现在也继续提取高德建筑轮廓（此前 style 0 在生成带调色板底图后直接返回，跳过了建筑层）。
- 锁屏行为不变：新的建筑轮廓需要 App 前台截图；锁屏只发送已经缓存的建筑/底图包，WiFi 链路本身不阻断缓存发送。

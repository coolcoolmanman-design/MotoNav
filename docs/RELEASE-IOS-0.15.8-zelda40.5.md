# MotoNav iOS v0.15.8-zelda40.5（塞尔达40周年特别版修订 5）

## 这一版换了思路：整个客户端强制白天（浅色）外观

前四版都是在深色 App 里逐控件“补白”，改一处漏一处。这一版按用户要求：
**取消自动白夜模式，全天强制白天（浅色）+ 透明玻璃**——固定背景（旗帜图）保持不变，界面控件全部走浅色。

### 具体改动

1. 根视图 `.preferredColorScheme(.dark)` → **`.light`**：整 App 强制白天外观。
   - 分段选择器（`UISegmentedControl`）、玻璃控件、按钮芯片全部天然浅色，不再需要逐个打补丁；
   - 语义色（文字/卡片/描边/粉青强调）本来就是动态双套值，自动切到浅色系，对比度由设计保证。
2. 玻璃控件（底部导航条、右侧竖栏、所有按钮/芯片）在 `light` 模式下**跳过 iOS 26 原生 glassEffect**——它对深色背景采样后仍偏深、且无视环境色覆盖；改为浅色毛玻璃 + 白色压层（0.48，保留透明感）+ 白描边，结果确定。
3. 分段选择器另加了 `UISegmentedControl.appearance()` 全局浅色外观，双保险。

## 安装

- 下载 `MotoNav-0.15.8-zelda40.5-unsigned.ipa` 侧载安装。
- 固件无需变动（配套 v7.12.10-ui.2-zelda40.2 即可）。

# MotoNav iOS 0.16.2.34（build 44）

配套固件：**musicA.38**（圆屏，App 与固件必须一起升级）

落地圆屏左划音乐页 **五套音乐样式**，设置入口在 **圆屏设置 › 音乐控制 › 音乐样式**（纯文字下拉，无缩略图），与开机动画 / 预设动态背景同一菜单风格。选择后即时下发，连接时 `pushAll()` 再同步一次。

## 一、圆屏设置 → 音乐控制 → 音乐样式

新增「音乐控制」分区，在原有蓝牙媒体按键 / 逐句歌词 / 封面旋转旁加入：

- **音乐样式** 下拉 5 项：原版·冷雾银（默认）/ 封面轮播 / 柔光立体 / 歌词主导 / 极简仪表
- 下发 `#MS,<0..4>`，圆屏存 NVS `mstyle` 并回执 `MS,<id>`
- 样式随选择即时同步；连上圆屏时 `pushAll()` 顺序含 `#MS`

逐句歌词仍走既有 `#ML` + LRCLIB 位图槽；各主题在歌词可用时叠 1–2 行静态歌词（v1）。

## 二、圆屏主题（固件 musicA.38）

| ID | 名称 | 要点 |
|----|------|------|
| 0 | 原版·冷雾银 | 现网圆封面 + 短臂黑针尖 + 冷雾玻璃三键；歌名下可叠歌词 |
| 1 | 封面轮播 | 圆角方封 + 邻封变暗；橙色方沿进度；中心橙播控；左右切歌 |
| 2 | 柔光立体 | 方封 + 霓虹播控球；底栏上/下一首；歌名/作者/歌词 |
| 3 | 歌词主导 | 大歌词居中；左上小圆封面 + 歌名/作者；底栏玻璃三键 |
| 4 | 极简仪表 | 外圈进度弧；小圆封面；大歌名；高对比白底播控 |

五套均保留 prev / play-pause / next 命中。

## 没动的部分

开机动画 `#BOOT`、六槽 `#FC2/#FC3`、动态背景 `#BG`、载具 `#FV`、封面旋转 `#RC`、路口放大图、屏保、BLE 协议头、刷机包结构。

## 升级注意

- 版本：根 `RELEASE_VERSION = 0.16.2.34`、`MARKETING_VERSION = 0.16.2.34`、`CURRENT_PROJECT_VERSION = 44`、固件 `7.12.10-ui.2-zelda40.9-musicA.38`。
- 旧 iOS 连新固件：样式保持 NVS 默认 0（原版）；新 iOS 连旧固件：旧固件忽略 `#MS`，设置页会显示「等待圆屏确认」。

# iOS 0.16.2.54

配套固件 `7.12.10-ui.2-zelda40.9-musicA.56`。基线 0.16.2.53。

## 本版 iOS 无功能改动

发版原因：与固件 musicA.56 对齐版本号，便于成组交付。

固件 musicA.56 修的是「矢量简图 id 13」中部折线的 4 处几何缺陷：
贴边 clamp 改成矩形裁剪出画、车吸附路线并固定在 (233,300)、
固定 200m 前向窗口让缩放恒定、16 点采样保留弯道 + 航向按时间平滑。

真实路线数据（bulk type 2）与 `#p` 定位本来就一直在发，且与地图主题无关，
因此 iOS 侧 `MapFeeder` / `Settings` / `CrossImageSender` 全部不动；
`CenterSpriteBridge` 的 `#CS` 索引、组合精灵 16 组合、时钟 schema=2 迁移
也保持不变。

## 建议实机验证

- 导航中切到第 7 种「矢量简图」：折线是否随实际路线转弯、过路口不倒退、
  不再出现贴边直线；低速 / 停车时整条线是否稳定不左右摇摆。
- 组合动画：16 组合是否选择即生效、预览与圆屏都正立、两轮车无黑底、
  sleep / chase 只按真实连接态切换。

# iOS 0.16.2.124

- **路口放大图箭头不再与道路撞色：**
  - 彩色槽（调色板第 5 色）原来取「所有高饱和像素的均值」，高德图里蓝色路线 + 绿地 + POI 图标 + 禁令牌一混合，均值变成低饱和脏色（真机实测 `(140,182,214)`，色差仅 74），和浅灰道路几乎同色，箭头糊在路面里看不清。
  - 改为把这批高饱和像素按色相分 12 桶，取像素最多的那一桶（面积最大的就是路线本体）算中心色；其它色相的绿地/图标一律不参与。
  - 中心色再做 HSV 提纯（饱和度拉满、保留色相与明度），确保和 4 档灰阶都拉得开；彩色槽固定在第 5 位，不再参与按亮度排序（旧版会把彩色槽按亮度塞进灰阶中间，nearest 量化就分不清了）。
  - 固件无需升级；仅改 App 端的量化配色，路口图尺寸/协议/分段发送不变。
- 基线：`cursor/home-looming-device-7f85` @ 0.16.2.123（FO-289 若隐若现圆设备），本稿保留该稿全部 UI 与「换一块圆屏」逻辑。
- 配对固件：路口配色修复对固件无版本要求；鸟瞰线建议 **musicA.139**（蓝线/红绿灯裁切到地网内 + 等红灯停稳切 2D 放大），否则可用 musicA.137+。

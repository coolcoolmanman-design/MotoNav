# MotoNav iOS 0.16.2.15（build 30）

## 导航 tab「最近去过」常驻

- 「去哪儿」卡内的**最近去过列表改为常驻显示**：规划好路线（已选目的地）后不再消失，
  可以随时从列表里一条点击直接换目的地 / 加途经点。
  - 仅当搜索框有结果时让位（搜索结果优先），清空搜索即恢复显示；
  - 位置移到卡片末尾（路线信息 / 开始导航按钮之后），不打断规划状态展示。
- 删除导航 tab 最下方独立的「最近去过」卡（内容已常驻在「去哪儿」卡内，避免重复）。
  「常用目的地」卡保留在导航 tab 底部不变。

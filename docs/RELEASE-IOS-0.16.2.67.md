# iOS 0.16.2.67

配套固件 `7.12.10-ui.2-zelda40.9-musicA.73`。基线 0.16.2.66 / musicA.72。
本版为 **FO-220 像素城市夜/昼双主题** 的配套包；FO-221 屏保表情包扩充完全在固件侧，App 不需要改。
安卓端本版不改。两份 release 保持 draft，不 publish。

## 变更（仅 2 个 Swift 文件）

- `Settings.swift`：`dynBgNames` 追加第 8 项 **「像素白天」**（index 7），下拉框从 7 项变 8 项；`#BG` 下发协议与第四字段（固定 0，不启用昼夜自动）均不变，固件已把 style 上限放宽到 `0..7`。
- `DeviceHomeViews.swift`：
  - 动态背景设置区文案由「7 种风格」改「8 种风格」；
  - 原「待机与动态背景始终深色」改为准确口径：辉光类 1..5 始终深色，「像素夜景」是冷白弦月、「像素白天」是太阳飘云，两者同构图、相位一一对应，**手动选择、不跟昼夜自动切换**；地图夜间配色仍由「圆屏显示」控制；
  - 右上 84px 预览圆屏 `DynamicBgDial.styleOverlay` 新增 `case 7`：亮青蓝渐变 + 8 向太阳日芒 + 3 朵飘云 + 灰蓝楼群 + 白色滚动虚线；`case 6` 的暖黄满圆同步改成冷白月牙（亮盘 + 右上挖盘），与固件新弦月对齐。
- `project.pbxproj`：`MARKETING_VERSION` 4 处 → `0.16.2.67`，`CURRENT_PROJECT_VERSION` 4 处 → `76`。

## 明确没有做的事

- **不加屏保特效开关**。用户拍板：App 侧屏保仍只有原来的「屏幕保护」总开关，选上即自动获得 16 表情 + 8 动效，不需要也不提供额外的「表情包 / 特效」选择器。
- **不做昼夜自动切换**。style 6 / 7 是两个独立手动主题，共用同一 LCG 序列与动态相位；跟系统时间或 `nightOn` 自动换主题会让「同一个城市」的对应关系失去意义，也会与辉光类始终深色的既有约定冲突。
- **不改字色**。白天版天空上半部保留中深蓝，就是为了兼容固件待机页固定的白色大时钟与槽位文字；若以后改成通亮晴空，需要另出一套深色 UI 方案。
- 不开机动画下拉框、不放风格缩略图（沿用既有 UI 口径）；预览继续复用壁纸卡右上的 `backgroundPreview` 圆屏。

## 配合固件

- FW musicA.73 把 `DynamicBg.h` 的像素城市拆成夜/昼两套配色：夜景暖黄满圆改冷白弦月（含光晕、环形坑、伴星），新增 style 7 白天（太阳日芒 / 飘云 / 玻璃反光 / 暖灰路面 / 红车绿骑手），两版楼群、道路、骑手逐帧对应。
- FW musicA.73 同时把 `Screensaver.h` 从 4 档睡意单眼型扩到 16 种参数化眼型 + 9 种装饰 + 8 组动作（弹簧形变 / 眨眼 / 球面转头尾迹 / 三点脉动 / 轨道环绕 / 惊跳拖尾 / 打盹点头 / 表情池漂移），零位图、脏矩形不扩大、30fps 与 45% 亮度不变。
- **必须同升 FW musicA.73**：App 单独升级只有多出一个下拉项和预览变化，圆屏上不会真的出现「像素白天」；固件单独刷了但 App 没升，则新主题选不到（旧 App 下拉框只有 7 项）。

## 建议实机验证

1. 侧载本 IPA + 刷 FW musicA.73，在「动态背景」里确认下拉框共 8 项、最后一项是「像素白天」，右上预览圆屏显示亮青蓝 + 太阳，选「像素夜景」时预览是月牙。
2. 分别选 6 / 7，确认圆屏回执 `BG,1,6,18,0` / `BG,1,7,18,0`；切回 1..5 辉光类时仍是深色，互不影响。
3. 静置进屏保，确认设置页没有多出任何新开关，只有原来的「屏幕保护」总开关。

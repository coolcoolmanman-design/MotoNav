# MotoNav iOS 0.15.16 · 音乐页专辑封面

配套固件 `v7.12.10-cover.1`。音乐控制页新增专辑封面圆盘显示，三端（固件 / iOS / 安卓）同步实现，旧客户端与旧固件互相兼容（无封面时维持原布局）。

## 本轮新增

| 项 | 内容 |
| --- | --- |
| 传输通道 | 新增 bulk type 5（复用地图大块传输的队列 / ACK / 优先级机制）；载荷 `'CVR'` 头 + zlib 压缩的 128×128 RGB565 方图，约 15~25KB，BLE 下约 2 秒/首，仅切歌时传输 |
| 圆屏布局 | 有封面时：r=64 封面圆盘居上（逐行圆形裁剪直写 framebuffer + 底环），歌名 / 歌手 / 按钮下移；无封面时完全保持原布局；封面布局下歌词暂不显示 |
| iOS 封面来源 | App 控制模式直读 `nowPlayingItem.artwork`；HID 模式（网易云 / QQ 音乐等）先匹配本地曲库（标题 + 歌手，MPMediaQuery），未命中走 iTunes 搜索 API 兜底（600x600bb 高清图，需联网） |
| 安卓封面来源 | MediaSession 直读 `ALBUM_ART` 位图或 `ALBUM_ART_URI`，无需网络兜底 |
| 缓存 | 封面按「标题|歌手」在手机端缓存，重复播放不重传 |

## 试法

1. 烧录固件 `v7.12.10-cover.1`（`app_0x10000.bin` 增量，保留 NVS）
2. 安装本版 IPA（0.15.16），连圆屏播放歌曲
3. 切歌后约 2 秒，音乐页出现封面圆盘；歌名 / 歌手 / 按钮下移
4. iOS HID 模式离线时，仅本地曲库匹配到的歌有封面；安卓始终离线直读

## 兼容性

- 旧版 App + 新固件：App 不发 type 5，圆屏保持原音乐页布局
- 新版 App + 旧固件：旧固件忽略 type 5，无副作用

## 脱敏说明

- 不含高德 Key、账号、设备序列号、私人路径
- iTunes 搜索请求仅含歌名与歌手，无用户标识

# iOS v0.15.8

## 修复

### 自行车路线规划失败（"自行车路线缺少分段"）

- 根因：高德 iOS 搜索 SDK 9.7.x 的骑行路径规划用 `showFieldsType` 控制返回字段，
  默认不返回分段扩展信息——`path` 有返回但 `steps` 里没有 polyline / 指令文本，
  解析后坐标点数为 0，触发"自行车路线缺少分段"。
- 修复：`AMapRidingRouteSearchRequest.showFieldsType = .all`，要求返回完整分段
  （坐标、指令、耗时）。摩托车路线走网页接口，不受影响。

### 底部实色填充栏移除（液态玻璃布局修正）

- 现象：底部液态玻璃导航条下方到屏幕底缘有一条页面底色的实色填充栏。
- 根因：旧布局为 VStack 上下排布，内容在导航条上沿被截断，下方露出页面底色。
- 修复：改为 ZStack 悬浮布局，内容 edge-to-edge 穿透到玻璃条后面被实时模糊
  （iOS 26 液态玻璃规范：内容连续、玻璃只做控制层）；滚动列表末尾加 116pt
  底部留白，最后一条内容可完整滚出。右侧竖栏模式（折叠屏外屏）不变。

## 升级方式

iLoader 侧载覆盖安装，设置与 Key 保留。

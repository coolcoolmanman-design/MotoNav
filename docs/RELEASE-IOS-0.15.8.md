# MotoNav iOS v0.15.8

## 本构建（停编 Zelda 特别版后的常规版）

- **恢复自动白夜**：外观跟随系统 / 可选手动浅色·深色；取消强制白天与 UIWindow 锁浅色。
- **去掉特别版背景与启动闪屏**：页面使用常规语义背景色。
- **导航 Tab 对齐 Apple Music**：悬浮液态玻璃胶囊（`GlassEffectContainer` + `glassEffect(.regular.interactive())`）；选中态为图标后软色圆晕，去掉近白实心胶囊以免盖住折射；内容滚过条后实时透色。
- **信息架构**：底部 4 Tab（出行 / 收藏 / 圆屏 / 我的），功能保留；Duo 底栏 / 外屏竖栏 / 展开双栏保留。
- Zelda 特别版客户端暂停发布；圆屏开机品牌里的「塞尔达40周年」选项仍可作为固件侧选择保留。

## 安装

- 下载 `MotoNav-0.15.8-unsigned.ipa` 侧载安装。
- 固件按既有通用版配套即可。

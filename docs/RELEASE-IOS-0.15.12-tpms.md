# MotoNav iOS 0.15.12-tpms

通用圆屏 7.12.0 配套 · 基于 0.15.11-tpms 的实测修正版。

## 本版改动（导航页实测反馈）

- **移除自绘路况光柱**：实机确认高德原生光柱在 `showUIElements=false` 下依然显示，
  自绘那条与之重复，删除（NaviBridge 的路况分段数据保留，随时可再启用）。
- **车速 chip 防截断**：模拟导航时 "60 km/h" 不再被同行按钮挤压成 "60…"。
- 其余同 0.15.11-tpms：顶部自绘转向卡（转向 + 距离/路名 + 到达时刻/剩余）、
  底部只剩一套控制行 + 长按退出胶囊、地图锚点下移。

## 安装

- unsigned IPA，iLoader 侧载；同 Bundle ID 覆盖安装，设置与配对保留。
- 校验：见 `SHA256SUMS.txt`。

## 已知说明

- 「更多」菜单里的"显示/关掉路况颜色"控制的是高德原生光柱。
- 连接动画电量读数需圆屏固件发 `V,pct,...` 通知，旧固件显示 "—"。

# iOS 0.16.2.27 — 修「首页/关于页版本号不跟着改」

## 修了什么

- **版本号显示改为就地读取**：`Config.swift` 里的 `APP_VERSION` 原来是手写常量（一直是 `iOS v0.16.2.25`），0.16.2.26 打包时只改了 `RELEASE_VERSION` 和工程 `MARKETING_VERSION`，于是 IPA 内是 0.16.2.26、首页脚注和关于页却仍显示 0.16.2.25。现在改成从 `Bundle.main` 的 `CFBundleShortVersionString` 取，和 Info.plist / 工程设置永远同步，以后不会再漏。
- 构建号 36 → **37**（上面那个原因），版本号 0.16.2.27。

## 与 0.16.2.26 的关系

功能部分与 0.16.2.26 完全相同（路口图浮窗 272×174），只是补上版本显示。**装过 0.16.2.26 的请改装本包**，否则页面上看到的仍是 0.16.2.25。

## 配套固件

圆屏 **musicA.28** 或更新（路口图按 272×174 校验尺寸）。

## 怎么验证

1. 装包后看首页底部脚注、设置页最下方「圆屏导航 · iOS v…」，应显示 **iOS v0.16.2.27**。
2. 设置 → 调试信息里的 `appVersion` 字段同样是 0.16.2.27，`build` = 37。

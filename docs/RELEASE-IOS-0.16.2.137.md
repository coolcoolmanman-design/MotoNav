# iOS 0.16.2.137 — 原生 3D 底图（P3D）发送链路（配 firmware musicA.163）

基线 0.16.2.136。**新增一条可选通路**：让高德按俯仰角直接渲染带透视的 3D 鸟瞰图，打包成 bulk
type 13 发给圆屏，固件只做「每行查表 + 横向等距采样」，不再逐像素挤楼块。默认关闭。

## 为什么固件还要参与

透视图和相机位置绑定：车往前 10 m，同一栋楼对应的屏幕行就变了（近处变多、远处变少）。
所以「一张透视图直接贴屏」只在停车时成立。固件只做重投影——每屏行查一次表把画布行/横向步长取出来，
没有楼块检测、没有楼高挤出、没有逐像素除法。导航线、车标仍走固件原来的 `t3dPt()`，
和底图共用同一套透视，天然对齐。

## 新增

- `Persp3DPacket.swift`（新）：16 色 RGB555 频次调色板 → RGB565、4bit 索引行优先、
  `(run-1, color)` 双字节游程，头 32B + 调色板 32B + 64 条 `{画布行, 每列毫米}`。
- `AmapCaptureHost.capturePersp()`：俯仰 46°、`rotationDegree` 按朝向（正负约定自动标定一次并记住），
  相机中心比车后移 90 m（车后那 1/4 屏才有画布像素）；用投影反解出画布顶/底行对应的距离，
  再按对数均分 64 条 LUT，全程只做投影查询、不重复渲染。
- `AmapSdkRaster.buildPersp()`：与栅格取图共用同一把 lease（同一个 MAMapView），
  取图 → 打包 → 记录 `persp-captured` 轨迹。
- `MapFeeder`：`TYPE_PERSP = 13`。仅在**样式 15/16 + 高德源 + 前台 + 底图已确认 + 蓝牙空闲**时补一帧；
  朝向变 10° 或挪 40 m 才换一帧，且距上次至少 7 s；`persp-failed` / `persp-ready` / `persp-send` 进轨迹。
- 设置页「原生 3D 底图（试验）」开关（`map_persp3d`），仅样式 15/16 可见。

## 带宽现实

bulk 约 5 KB/s，448×448 4bit 游程后大致 20~50 KB → 4~10 s 一帧。
所以这一版的验收目标是**停车 / 等红灯 / 直路巡航**能出参考照那种楼块与立交桥透视；
车头朝上的连续 3D 需要先提链路速率（BLE 2M PHY / 更大 MTU / WiFi 旁路），那是下一步。

## 回退

关掉开关即完全回到 0.16.2.136 行为；固件侧没收到 type 13、或朝向差 > 8°，也会自己回退到
`rasterRows3D`，不会空屏。

## 配对

- 固件 **musicA.163**（含 `parseP3D` / `p3dDrawRows`）；更早的固件会忽略 type 13。
- 建议同时升级 iOS 与固件；固件低于 .163 时开关无效。

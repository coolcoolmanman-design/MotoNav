# MotoNav iOS v0.15.8-zelda40.4（塞尔达40周年特别版修订 4）

## 这次改的是根因

前三版（zelda40.1 ~ .3）都在给 iOS 26 的原生 `glassEffect` 加白色 tint，但**液态玻璃的底色由它对背后内容的采样决定**：本特别版是固定深色背景，玻璃采样后仍然偏深；且 `glassEffect` **完全不理会 `.environment(\.colorScheme, .light)` 覆盖**——这就是改了三次都没效果的原因。

zelda40.4 不再依赖系统玻璃的采样结果：

1. **玻璃控件（底部导航条、右侧竖栏、所有按钮/芯片）跳过 iOS 26 原生玻璃**，改用「浅色毛玻璃 + 明确的白色压层（0.55）+ 白色描边」，结果是确定的浅色，与背景无关；控件内文字/图标仍取浅色语义（深色字）保证对比度。
2. **分段选择器也补上了**：设置页的「刷新速度 / 预判 / 走过的路线 / 夜间配色 / 导航条摆位」是 `UISegmentedControl`，深色模式下铁定深灰底。这次同时加了白夜环境覆盖和 UIAppearance 全局浅色外观，双保险。

## 安装

- 下载 `MotoNav-0.15.8-zelda40.4-unsigned.ipa` 侧载安装。
- 固件无需变动（配套 v7.12.10-ui.2-zelda40.2 即可）。

# MotoNav iOS 0.16.2.6-tpms

Draft-only · 配对固件 `7.12.10-ui.2-zelda40.9-musicA.3`。

基线：`0.16.2.5-tpms`。本包修复 0.16.2.4/5 真机实测的底栏图标消失与连接模型过暗、黑屏、侧键/开孔错误。

## 本包

1. **底栏恢复四个图标与文字**
   - 选中玻璃回到标签 `background` 内，标签始终处于玻璃上层
   - 未选中标签改用高对比深色；选中标签才使用白色
   - `GlassEffectContainer` 只负责标签间的选中玻璃融合，底栏底色不再参与融合
   - 保留点击、按住拖动、速度拉伸与松手吸附；蓝色 tint 与高光降噪
2. **连接设备模型按实物修正**
   - 提高银色材质与环境亮度，保留喷砂颗粒和 R0.15 圆润外圈
   - 内置导航屏纹理：地图网格、蓝色路线、左转/200 m、28 km/h；不再回退纯黑/灰屏
   - 两个侧键恢复竖向，位于右侧上/下方；中间 5 孔改为贴壳圆孔，不再用凸出黑球
   - 屏幕玻璃反射减淡，避免遮住 UI
3. **版本** `MARKETING_VERSION 0.16.2.6` · `CURRENT_PROJECT_VERSION 21` · `APP_VERSION iOS v0.16.2.6-tpms`

## 安装

同 Bundle ID 覆盖安装 `0.16.2.5-tpms`；固件保持 `musicA.3`，无需重刷。

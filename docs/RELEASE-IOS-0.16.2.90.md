# iOS 0.16.2.90 · musicA.99

天地图底图 + 高德建筑轮廓混合路径；前台预缓存，锁屏只发已缓存包。Draft-only。

## 本版变更

- **混合底图**：地图来源「天地图」时圆屏底图仍走 `vec_w` HTTP；罪恶都市 + 开启「俯视建筑轮廓」时，用高德双截图把楼块叠到天地图底图上（同套 RLE/BLE）。
- **前台预缓存**：选线后在前台沿线缓存天地图底图与（可选）建筑包。
- **锁屏只发缓存**：非 `.active` 时不新开高德双截图 / 轮廓提取；可继续发已缓存包，天地图 HTTP 底图仍可补缓存，但建筑步骤推迟到回前台。
- **不恢复 SoftAP / WiFi 地图加速**。

## 版本

- iOS `0.16.2.90` · build `99`
- 配套固件仍为 `7.12.10-ui.2-zelda40.9-musicA.99`（未改固件）

## 自测要点

1. Key 设置：高德 + 天地图服务端 Key。
2. 圆屏设置 → 小地图 → 地图来源 **天地图**；风格 **罪恶都市**；打开 **俯视建筑轮廓**。
3. 前台规划短途：等沿线缓存；状态可见天地图底图，随后「天地图底图 + 高德建筑轮廓」。
4. 锁屏短导航：应继续用已缓存包；不应再开新的楼块提取（回前台后可补）。

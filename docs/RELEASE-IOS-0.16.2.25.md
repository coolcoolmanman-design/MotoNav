# iOS 0.16.2.25 — 路口放大图下发排查版

## 修了什么

- **透明背景导致整张图近黑**：高德给的路口图常带透明底，之前直接按 alpha=0 压成索引 0（0x0E1116），圆屏上就是一块黑卡片，看着像「没有路口图」。现在先在画布上填深色底（0x1A1F27）再绘制，透明区域也有地面色。
- **能力位自愈**：固件只在认证后广播 3 轮 CAP，通知订阅晚一点就可能整轮错过，`crossSupported` 永远是 false，图根本不发。现在没确认支持时也会硬发一次（旧固件对 type 9 直接丢弃，无副作用），只要圆屏回 `K,9` 就自愈成已支持。
- **调试卡显示下发结果**：`已下发 xxKB id=N`，不再是只有一句「路口图处理中」。

## 怎么验证

1. 装本包 → 连圆屏 → 跑一次导航（模拟导航即可）。
2. 「设置 → 调试信息 → 路口图」应显示 `#序号 尺寸 比例 PNG 体积 | 已下发 xxKB id=N`。
3. 若显示 `固件不支持路口图（< musicA.26），未下发`，说明圆屏不是 musicA.26+，需要重刷固件。

# iOS 0.16.2.48

配套固件：`7.12.10-ui.2-zelda40.9-musicA.51`（建议一起升级）

基线：musicA.50 / iOS 0.16.2.47（`ff9c53a`，自定义精灵 + 电量管理）。

## 1. 新增第 7 种地图样式「矢量简图」(id 13)

按用户确认的参考图落地，与已上线的第 6 种「大字转向」并列，不改动旧样式：

- 昼 `#0A63FF` 蓝 / 夜 **`#19E3B1` 薄荷绿**（严格按参考图，非琥珀黄）。
- 左上超大转向箭头 + 并排超大距离数字；中部一整块极简矢量路口简图（路线折线 / 主干道 / 绿地 / 车头箭头）。
- **车道指引完全由中部胶囊承载**（复用 `#j` 的 `laneN/laneBg/laneFr`，推荐车道亮主色）；底部车道条不再绘制。
- 路口放大图在该样式下仍隐藏，App 直接跳过路口图的量化、编码与 BLE 传输。
- **不做红绿灯倒计时胶囊**（高德无公开倒计时数据）。
- 保留超速红弧 / 红边 + 红色车速；限速牌、时间 · 剩余里程照常。
- 不下载栅格底图、不跑建筑块，`THEME_NO_BASEMAP` 白名单加 13。

## 2. 设置

圆屏设置 → 圆屏显示 → 风格下拉第 7 项「矢量简图」，纯文字、无缩略图；默认仍是「罪恶都市」。
协议零改动：`#t,13,1`，老固件收到会静默忽略。

## 3. 兼容性

- 老 App 无第 7 项；新 App 连老固件时选项下发 `#t,13,1` 会被忽略，不影响其它样式。
- iOS 0.16.2.47 的中央槽自定义精灵、电量管理全部保留，无回退。

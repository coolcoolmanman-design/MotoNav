# iOS 0.16.2.97 · musicA.106

两套新动画 + 闲置自动关机开关配套包。Draft-only。新增一条命令 `#IDLEOFF`（旧固件忽略，安全降级）。

## 本版

- **配套固件 musicA.106**：两套重新绘制的待机/连接态动画（尺寸规格不变）；新增未插电闲置 5 分钟自动关机开关。
- 我的 → 通用 → 电量管理 → 自动息屏与关机：新增「闲置自动关机（仅电池，约 5 分钟）」开关，默认开。连接圆屏后自动从设备同步状态，切换后发 `#IDLEOFF,1/0` 并有 ACK 回执确认。
- 关闭后设备不会自动关机；重新开启从满 5 分钟计时。

## 版本

- iOS `0.16.2.97` · build `106`
- FW `7.12.10-ui.2-zelda40.9-musicA.106`

## 刷机

1. 分区表 `0x8000` → app `0x10000` 刷 musicA.106
2. 装本 Draft IPA
3. 电量管理里切换闲置自动关机开关，确认状态回显

## 兼容

- 新 App + 旧固件：发 `#IDLEOFF` 被忽略，开关仅存本机，其余功能不受影响。

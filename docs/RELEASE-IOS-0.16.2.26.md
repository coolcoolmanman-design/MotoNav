# iOS 0.16.2.26 — 路口图改浮窗（B 方案）

## 改了什么

- **路口图从整页卡片改成浮窗**：`CrossImageSender` 的缩放尺寸由 380×243 改为 **272×174**（同样 25:16，不裁切不变形）。整页版把导航上下文全盖住了，圆屏上下还留大片黑边；浮窗版地图、车头、转向牌、行程行全都保留。
- 深色化、16 色量化、nibble RLE 的算法没有变化，只是画布变小，单包从 12~20KB 降到 **6~12KB**，路口前那几百米推得更快。
- 设置页「路口放大图」的说明文案同步更新为浮窗描述。

## 配套固件

圆屏需要 **musicA.28** 或更新版（固件侧按 272×174 校验尺寸，尺寸不符会整包丢弃并在串口打 `[CROSS] parse: 尺寸 ... != ...`）。旧固件 musicA.26/27 是 380×243，与本包不匹配。

## 怎么验证

1. 圆屏刷 musicA.28 → 装本包 → 连圆屏 → 跑导航（真实或模拟）。
2. 接近路口时，圆屏上半出现圆角浮窗，里面是路口放大图；浮窗下方能看到自己的车头和前方道路。
3. 串口应打印 `[CROSS] parse ok 272x174 ...` 与 `[CROSS] overlay on`。
4. 若浮窗一直不出现，先看串口尺寸报错，再看设置页「路口放大图」是否被关掉。

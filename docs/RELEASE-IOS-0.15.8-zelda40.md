# MotoNav iOS 0.15.8-zelda40 · 塞尔达40周年特别版

基于 0.15.8 的纪念版客户端，版本号不占序号（不改 0.15.9）。

## 新增

- **启动画面**：App 打开时显示塞尔达 40 周年纪念旗淡入 → 停留 → 淡出（约 2.9 秒）
- **固定背景**：暗金三角纹理铺满 + 居中纪念旗（原图水印已裁除），随页面滚动固定不动
- **开机画面品牌新增「塞尔达40周年特别版」**：与固件 v7.12.10-ui.2-zelda40 的开机动画（品牌 ID 17）配套，连接圆屏后可一键同步

## 修改

- 取消自动白夜模式：背景为固定纪念图，界面强制深色（原「外观」设置卡移除；圆屏小地图昼夜配色不受影响）
- 版本号显示 `iOS v0.15.8-zelda40`

## 兼容性

- 需搭配固件 v7.12.10-ui.2-zelda40（或任意支持开机品牌 ID 17 的固件）使用开机动画
- 其余功能与 0.15.8 完全一致

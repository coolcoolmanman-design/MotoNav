# MotoNav iOS 0.16.2.30

配套固件：**musicA.31**（圆屏）

## 本版包含两批改动

### 1. 路口放大图两段式（0.16.2.29 那一批，之前那次 CI 没跑完）

实测每片 BLE 分片固定 91~101ms（锁屏时 iOS 把连接间隔拉到 ~90ms），跟包大小无关、只跟片数成正比。
所以不跟单包较劲，直接减片数：

- 先发 **136×87 预览**（bulk type 10，约 5 片，0.4~0.6 秒上屏），圆屏 2 倍放大顶上；
  随后 **272×174 全图**（type 9）替换成清晰版。
- 调色板 16 色 → **5 色**（4 级灰 + 1 个彩色槽），包体再降三成。
- 协议 `ver=2`；`ver=1` 旧包仍然接受。
- bulk 队列分片带优先级：预览 20 > 全图/路线 10 > 底图 0，保证顺序一定是「预览 → 全图 → 底图」。

### 2. 圆屏电量显示「—」（修复）

- `V,-1` 只是「这次没读到」，不再把已有的电量清成 nil（以前一收到就变「—」）。
- 固件侧也修了根因：屏保期间不轮询电量、连上后不立即推送、油量计越界被当成没电池。

## 验证

- 圆屏 tab 的「设备电量」应在连上后 5 秒内出现具体百分比（不再长时间显示「—」）。
- 接近路口：先看到略糙的浮窗（预览），0.5~1.5 秒后被清晰版替换。
- 串口对应 `[CROSS] parse ok preview ...` → `[CROSS] parse ok full ...` → `[CROSS] overlay on`。

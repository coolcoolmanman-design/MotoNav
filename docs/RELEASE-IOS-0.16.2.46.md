# iOS 0.16.2.46

配套固件：`7.12.10-ui.2-zelda40.9-musicA.49-ui.6`（建议一起升级）

## 1. 地图新增第 6 种样式「大字转向」

按参考图新增一种**无底图大字排版**：超大转向箭头、超大距离数字（含小单位）、路名、车速、外圈进度弧。
在「圆屏设置 → 圆屏显示 → 风格」下拉末尾选择，纯文字、无缩略图，默认仍是「罪恶都市」。

- 昼夜两套主色严格按参考图：白天晴空蓝底 + 蓝色箭头/进度弧，夜间深蓝底 + **琥珀黄**箭头/进度弧、白色文字。
- 选中该样式时**路口放大图与车道自动隐藏**（固件侧 `crossReady()` / `mapModeActive()` 双门控）。
- **保留超速红边与电量**（含蓝牙连接点）；不画顶部大速度块，改为路名下方的小字车速。
- 不下发栅格/矢量底图（与龙珠雷达同一条省流路径），比现有 5 种样式更省流量与算力。
- 协议零改动：沿用现有 `#t,12,1`（`THEME_N` 从 12 扩到 13）。老固件收到 12 会静默忽略，老 App 不显示新选项，双向兼容。

## 2. 音乐封面「风格化背景」

把原来的「抽一个平均色刷满圆内」换成**由封面图像本身做风格化处理**：保留封面的大尺度明暗、色块与构图，随切歌自动变化。

- 档位由本版定为 **3 档 + 关闭**（强度固定标准档，避免设置菜单过长）：
  `关闭（原纯色氛围底）` / `放大虚化`（默认）/ `色块马赛克` / `双色海报`。
- **5 种播放样式数量不变**（`#MS,0..4` 一字未改）；原「极简仪表」硬编码的 `0x1082` 深底已去掉，统一吃风格化背景。
- **固件端自算**：对 `coverImg` 128×128 RGB565 做中心 1.55× 裁切、降采样/模糊、压暗 40%、去饱和 15%、径向暗角，只在**换封面或换档位**时算一次并缓存 466² 整屏；播放中每帧只做一次内存拷贝，无 BLE 传输、无新增 bulk、老 App 不用升级。
- 新增短命令 `#MBG,<0..3>` 与 NVS 键 `mbg`，回执 `MBG,<mode>`；未知 `#` 命令在旧固件被静默忽略。
- PSRAM 分配失败时自动退回原来的 `coverAmbient` 纯色，不会让音乐页崩溃。

设置位置：「圆屏设置 → 音乐控制 → 封面背景」，与「播放风格」同款纯文字下拉。

## 3. 升级注意

- 固件主题不存 NVS，连接后由 App `pushAll()` 下发；新样式与背景档位会在连接/重连时自动同步。
- 音乐页不读 `nightOn`，也不走 `bgSrc()`，与昼夜配色、自定义壁纸、待机动态背景互不干扰。
- 刷机请用 `..._app_0x10000.bin`（不擦 NVS）。

## 4. 仍待实机验证

- 大字转向：昼夜两套配色的实际可读性、超大箭头与数字在不同路名长度下的排版、导航进出与到达特效让位。
- 封面背景：4 档在真实专辑封面上的观感、换封面瞬间的一次性计算耗时、样式 0 旋转播放时 42ms 帧预算、PSRAM 峰值与温升。

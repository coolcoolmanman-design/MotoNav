# MotoNav iOS 0.16.2.38（build 48）

配套固件：**musicA.40**

## 圆屏设置 · 待机六槽改版（效果图定稿落地）

- 始终深色待机 / 动态背景；删除「昼夜随时间自动切换」与「一键主题包」。
- 「预设动态背景」改名「动态背景」；「开机动画」补标题；「待机壁纸」标题字号与其他分区一致。
- 音乐控制下拉上方加「播放风格」标题。
- 六槽顺序：连接态 + 电量开关（并列）→ 左上 → 右上 → 上方 → 下方 → 中央。
- 上方槽：时间 / 隐藏；中央槽：动画 / 时间 / 全屏指针表盘 / 隐藏（分段控件同左上）。
- 中央下挂：时间样式 / 动画样式 / 指针样式（按模式出现）。
- 全屏指针时四功能槽设置灰显；侧槽默认速度 / 胎压 / 天气 `{0,2,3}`。

# MotoNav iOS 0.15.18-tpms

通用圆屏固件 **7.12.11-opt.4** 配套 · 基于 `0.15.17-tpms`（IA + basemap）叠 **实机 UI 修正**。

**本包为 Draft / 脱敏侧载包，供自测；未对 main 合入、不推上游。无公开 PR 编辑。**

## 本版内容

- **连接动画**：去掉模型下方蓝色描线/圆环；软椭圆地面阴影；HD 导航屏贴居中；**每次连接（含断开后再连）都播放**。
- **Tab**：轨迹记录→**轨迹**（去掉底栏「开始记录」）；设备→**圆屏**。
- **圆屏卡**：正视产品透明 PNG；去掉「1.85B」「存储卡 已就绪」文案；**圆屏显示** / **圆屏设置** 二级入口；胎压全字段 + 轮胎图缩小。
- **我的**：通用副标题「外观与key」；删除「圆屏与连接」「胎压监测」；「导航语音」/「关于」副标题按 field 反馈。
- 保留 0.15.17 basemap 道路分类修正与冷淡科技色板。

## 固件

- **请同时刷入** `7.12.11-opt.4`（独立 firmware Draft）。本工作流附带的 panel0 zip 可能仍为分支内源码构建基线。

- IPA：`MotoNav-0.15.18-tpms-unsigned.ipa`（unsigned 侧载）；同 Bundle ID 覆盖安装。
- 高德 Key **不在包内**。

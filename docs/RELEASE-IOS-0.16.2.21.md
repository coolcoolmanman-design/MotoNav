# iOS 0.16.2.21（build 36）

本轮三项调整中的 App 部分：

## 变更
1. **导航结束不再弹 OK 确认卡**：到达目的地后显示一张 1.6 秒的轻提示（「行程已结束 · 即将返回主页」，不可点击），随后自动结束导航并退回主页。原来的常驻「OK」按钮已删除。
2. **待机壁纸迁入「圆屏设置」**：原「圆屏 Tab → 自定义开机背景」卡片移到「圆屏 Tab → 圆屏设置」内（开机动画下方），名称改为**待机壁纸**；功能不变（选图 / 裁切 / 推送 / 恢复默认，开机连 App 自动重推）。圆屏 Tab 首页不再显示该卡片。
3. **六槽表盘功能名**：「G值」→「实时G值」，与固件 musicA.21 的显示口径一致（槽内显示当前 G，不再显示峰值）。
4. 版本号同步（APP_VERSION = iOS v0.16.2.21）。

## 安装
unsigned ipa，照常 iLoader 侧载。G 槽实时值需配合固件 musicA.21。

# iOS 0.16.2.18 (build 33)

对应固件 musicA.18。

## 修复（配合固件）
1. 自定义开机背景：背景卡改为**圆形预览**（与电子吧唧一致）+ **裁切**按钮（复用吧唧裁剪编辑器，自选区域/自动居中）。
2. 表盘设置：左上/右上/下方功能槽新增**隐藏**选项。

## 新增
3. 电子吧唧卡新增**图片 / 文字滚动**模式切换：
   - 文字滚动：文本输入 + 5 档字号（小/中/大/特大/超大）+ 6 色文字（白/金/青/绿/橙/粉）
   - 「上传文字」把文字渲染成宽位图（黑底彩字）推送到圆屏并自动切滚动模式
   - 图片模式行为不变；导航中自动退出
4. 连接圆屏后自动同步吧唧显示模式（#BT）。

## 说明
- 修复了 musicA.17 推送开机背景固件无反应的问题（App 端无需操作，重推即可）。

# MotoNav iOS v0.15.11-tpms

在 0.15.10-tpms（胎压卡片 + 连接动画）基础上，修复导航页底部控件与高德自带 UI 重叠的问题。

## 导航页整合重构

**问题**：导航时 App 的玻璃控制条（已静音/暂停/车速/设置）和"长按退出导航"胶囊，与高德导航视图自带的"退出 | 到达 | 设置"底栏、logo、"主页"按钮叠在同一区域，互相遮挡。

**方案**：高德导航界面自带 UI 全部隐藏（`showUIElements = false`），功能全部整合进 App 玻璃层，一个不丢：

| 高德自带 | 去向 |
|---|---|
| 底栏「退出」 | 「长按退出导航」胶囊（0.6 秒防误触，原样保留） |
| 底栏「xx:xx 到达」 | 顶部自绘转向卡右侧：到达时刻 + 剩余里程/时间 |
| 底栏「设置」 | 「设置」chip |
| 顶部转向面板 | 自绘深色转向卡：转向箭头 + 距离 + 路名（数据来自 NaviBridge） |
| 右侧路况光柱 | 自绘光柱（畅通绿/缓行黄/拥堵红，按全程比例分段） |
| 「主页」（全览/跟随）、路况开关 | 仍在「更多」菜单 |

- 地图锚点下移（车标偏下，前方视野更大）
- 底部永远只有一套控件，任何导航/模拟导航状态下不再重叠
- 夜间：地图走高德夜间配色，玻璃层随 AppTheme 自动切换

## 安装

- 同 Bundle ID 可覆盖安装（iLoader 侧载）
- `MotoNav-0.15.11-tpms-unsigned.ipa` 为未签名包

## 注意

- 胎压卡片与连接动画与 0.15.10-tpms 一致，无改动
- 圆屏固件建议搭配 7.12.x 通用版

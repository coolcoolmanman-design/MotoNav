# MotoNav iOS v0.15.8-zelda40.3（塞尔达40周年特别版修订 3）

## 改动

1. **全部玻璃控件改白夜透明**：zelda40.2 只改了底部导航条/右侧竖栏，截图反馈发现所有 `GlassButton`/`GlassChip` 控件（摩托车/自行车路线规划、连接/断开、粘贴高德分享的路线、收藏、搜索等）仍是深色底纹。本次统一：
   - 玻璃底一律显式白染（白夜透明观感）；
   - 品牌色（粉/青/橙/红）改为白玻璃上的淡色提示层；
   - 控件内文字/图标强制取浅色语义（深字），保证白玻璃上的对比度。
2. 选中态软胶囊、强调色均为动态色，跟随浅色环境自动切换。

## 安装

- 下载 `MotoNav-0.15.8-zelda40.3-unsigned.ipa` 侧载安装。
- 建议与固件 v7.12.10-ui.2-zelda40.2 配套使用。

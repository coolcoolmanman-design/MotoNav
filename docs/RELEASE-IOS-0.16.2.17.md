# MotoNav iOS 0.16.2.17（build 32）

固件配对版本：**7.12.10-ui.2-zelda40.9-musicA.17**（六槽表盘 + 自定义开机背景）。

## 六槽表盘设置（替换原「组件槽自定义」）

- **左上 / 右上 / 下方槽**：功能四选一（速度 / G值 / 胎压 / 天气）+ 独立颜色，实时下发 `#FC2`，圆屏秒切。
- **固定槽**（时间槽 / 连接态 / 中央动画）：显隐开关 + 独立颜色；电量固定顶部显示不占槽。
- **中央动画载具**：塞尔达×摩托 / 像素小人×摩托 / 小人×自行车 三选一，`#FV` 下发。
- **一键主题包**：经典白 / 暖橙 / 冷青 / 复古，一键套用全部槽位颜色。
- 旧固件（无 #FC2）发命令会被忽略，设置项显示「等待圆屏确认」。

## 自定义开机背景（圆屏 Tab 新卡片）

- 相册选图 → 居中裁方 → 466×466 RGB565 → zlib → BLE bulk **type 8** 推送；待机页即刻生效。
- **持久化 = 开机连 App 自动重推**：App 本地保存最后选的图（Documents/bg_custom.png），圆屏认证后广播 `CAP,BGR,1` 时自动重推；掉电/重启都不丢。
- 「恢复默认」：发 w=h=0 清除包并删除本地存图，圆屏回 faceId 表盘背景。
- 导航 / 巡航 / 网页模拟导航中禁止推送（bulk 通道让位给地图）。

## 兼容性

- 最低 iOS 15 不变；新文件 BackgroundBridge.swift / BackgroundPacket.swift 已注册进工程。
- 与 0.16.2.16 的差异仅为表盘设置区 + 背景卡，导航 / 音乐 / 胎压 / 吧唧等不受影响。

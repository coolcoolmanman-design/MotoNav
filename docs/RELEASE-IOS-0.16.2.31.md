# MotoNav iOS 0.16.2.31

配套固件：**musicA.32**（圆屏，必须一起升级）

## 本版做了什么

### 1. 路口放大图按昼夜出两套配色

之前路口图是「永久夜间」：不管手机地图白天还是夜间，App 都固定做灰阶反相 + 深底，
固件也固定深色投影和描边。白天浅色地图上就贴着一块夜间深色浮窗。

- `CrossImageSender.deepScene` 现在读 `Settings.shared.paletteNight`：
  - **夜间**：灰阶反相（`白→20、黑→160`）、底铺 `(26,31,39)`、彩色提亮到深底上可见；
  - **白天**：保留高德原图浅底深线的明暗（`24 + lum×0.84`）、底铺 `(244,244,240)`、彩色保持原色。
- `Settings.applyDayNight()` 在昼夜切换时调 `CrossImageSender.onPaletteChanged()`，
  把正在显示的那张路口图按新主题重发；指纹里也混入了昼夜位，同一张图不会被 hash 判重跳过。
- `hide()` 会清掉缓存图，避免过了路口后昼夜切换又把旧图冒出来。
- 固件侧描边跟着 `nightOn` 切（夜间青绿 / 白天深灰），浮窗不再是深色专属外框。

调色板本来就是随包下发的 **5 色**，所以昼夜配色不需要改协议，固件只做索引→像素映射。

### 2. 第 5 个彩色槽锁给引导路线

高德路口图里除了路线还有绿地、POI 图标、禁令牌，以前把所有彩色像素取均值会得到脏色。
现在只取**色差 ≥70** 的高饱和像素做均值，基本只剩路线本体；灰阶四档边界也改成按本图
实际亮度 min/max 动态四等分（夜间亮度落在 20~160、白天 24~238，写死一组会让其中一套色带挤成一团）。
效果接近竞品那种「画面里只有引导线是强调色」。

### 3. 浮窗尺寸与固件同步调整

| | 旧 | 新 |
|---|---|---|
| 全图 | 272×174 | **272×150** |
| 预览 | 136×87 | **136×75** |
| 窗口上沿 | 72 | 96（下沿仍 246，让开车头） |

窗口更扁（1.81:1），顶部给车速/单位留出 20+px（旧版车速数字底边约 74 和窗口顶 72 只差 2px，会压字），
固件侧圆角 18→6、去掉双层投影，卡片视觉重量降下来。

## 验证

- 白天（设置里把「夜间配色」切到「白天」）接近路口：浮窗应是**浅底深线**，和圆屏白天地图成套；
  切到「夜间」或等日落，同一张浮窗应变成深底反相版。
- 昼夜切换那一刻如果正显示路口图，圆屏上的浮窗应跟着换色，不会一直留着旧色调。
- 串口：`[CROSS] parse ok preview 136x75 ...` → `[CROSS] parse ok full 272x150 ...`。
- 车速数字（顶部 120）底部不应再被浮窗压住。

## 兼容性（重要）

- **尺寸两端必须同步**：`CrossImageSender.W/H/PW/PH` ↔ 固件 `CROSS_W/H/PW/PH`。
  本版改了高度，**App 和固件必须一起升级**，否则整包被丢弃、路口图不显示（其余功能正常）。
- 协议仍为 `ver=2`，`ver=1` 旧包固件仍兼容。

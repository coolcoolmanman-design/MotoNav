# musicA.153（配 iOS 0.16.2.136）

按第三次实机反馈继续对齐参考营销图：**恢复红徽里的数字**、给图标内部补上**渐变**、
加深**字体软影**、重做**底部胶囊**；同时 iOS 侧修复样式 16 天地图瓦片"时有时无"的残留问题。

## 1. 右侧红徽：恢复数字（.152 改成固定摄像头是误判）

参考稿放大后红徽里是**白色数字"14"**（DIN 分段风格 = 剩余分钟），不是测速摄像头。
.151 先把它改成摄像头、.152 又固定死，导致用户看到"数字消失了"。本轮恢复：

- 深红底 **顶亮底暗渐变**（参考稿采样顶 `0x4862` → 底 `0x2821`）+ 浅红描边 `0xDBD0`；
- 有 ETA 时用 GA_B 白色数字居中显示剩余分钟（带软影）；
- 仅在确有电子眼时，数字下方保留一枚 2px 小红点作提示，不侵占数字主体。

## 2. 图标内部渐变（原来全是纯色，显扁平）

参考稿的图标内部都不是一个色：车速圆、红徽、车道胶囊、底部胶囊都有"顶亮底暗"的纵深。
本轮新增两个渐变工具 `dnGradDisc()` / `dnGradPill()`（顶色→底色线性插值 + 边缘抗锯齿），应用到：

- **车速圆**：顶 `0x74B2` → 底 `0x0AAB`（夜景相应压暗），保留 3px 浅灰描边；
- **红徽**：见上；
- **车道胶囊**：推荐车道顶 `0x10B4` → 底 `0x0455`（夜景对应深青）；
- **底部胶囊**：顶 `0x0738` → 底 `0x012E`（夜景对应深青）。

## 3. 字体软影加深

实机数字/时间的阴影比参考稿淡。提高影心不透明度并略增羽化：

- 时间 110→165、大距离数字 150→185、车速数字 110→170、胶囊文字新增软影 120。
- 全部走整串软掩膜 + 两遍盒式模糊，仍是真羽化，不会出现硬黑边。

## 4. 底部胶囊

从纯色填充改为深青渐变（见第 2 节），并给胶囊文字加软影，避免亮底上"漂浮"。

## 5. iOS 侧瓦片时有时无（0.16.2.136）

样式 16 纳入 buildingMode 后，天地图源同时被"HTTP 底图"和"高德截图建筑任务"两套逻辑拉扯：

- 锁屏 `setRenderingAvailable(false)` 因 `buildingMode` 无条件 `workToken.cancel()`，
  打断在途天地图 HTTP 下载；→ 纯 HTTP 源（天地图 / 高德锁屏回退）不再 cancel；
- `movement-cancel` 硬编码 `mapSource == SRC_AMAP`，天地图源在途建筑提取无法被移动打断，
  阻塞新块；→ 去掉来源限制；
- `acceptChunk()` / `useCachedMap()` 的三个早退分支在 ACK 丢失后没有超时逃逸，
  旧包永久占据 chunk；→ 加 8s ACK 丢失逃逸 + 未确认包不参与缓存早退。

固件协议与 BLE 传输均不变。

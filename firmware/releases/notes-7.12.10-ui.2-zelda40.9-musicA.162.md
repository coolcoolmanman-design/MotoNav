# MotoNav firmware musicA.162

配套 iOS：**0.16.2.136**（无需升级）

## 相对 .160 的变更

### 外圈倒计弧：改成「越过顶部的暗槽 + 从左往右填满的光柱」

`.160` 把弧理解成「左下独立的一小段（−140°~−78°，62°）」，这是把真机拍摄里的边缘反光当成了弧本身。实际 UI 是一条环形的**槽**：

| 元素 | 参数 |
|---|---|
| 槽 | **−109° → +109°**（约 7:40 位 → 12 点 → 4:20 位），跨度 **218°**，宽 4px、半透明纯黑，导航中常显 |
| 光柱 | 从 −109°（左侧底部）沿弧往右增长，长度 = 218° × 进度，宽 5px、浅青 (148,228,255) |
| 头端粉点 | 落在 −109° + 218° × 进度，跟着光柱由左侧底部往右走，50 米内呼吸放大 |

关键点：

- 槽与光柱都是从**左侧底部往上绕过顶部**再到右侧底部，与「绕底部」的下半圈版本方向相反（`.161` 内部迭代过一版绕底部的，未发布）；
- `arcBand()` 单段必须 < 180°，所以槽和光柱都在 12 点处切两段，并**重叠 1°**，否则接缝两边各按抗锯齿画一半会留一道淡缝；
- 进度仍是 `ringShown`（`(STAGE_FAR_M - navDist)/STAGE_FAR_M`），到路口时槽正好填满。

### 位置参数

`dnGlassCountRing()`：

```cpp
const float A0 = -109.0f, SPAN = 218.0f;   // 槽：12 点两侧各 109°
```

只改这两个数即可调整起止与跨度。

## 刷机

```
esptool --chip esp32s3 --port COM5 --baud 921600 --before default_reset --after watchdog_reset \
  write_flash 0x8000 <partitions_0x8000.bin> 0x10000 <app.bin>
```

**不要**写 `full_0x0.bin`。

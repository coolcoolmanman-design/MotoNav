# MotoNav v7.12.10-ui.2-zelda40.3（塞尔达40周年特别版修订 3）

塞尔达40周年特别版第三批实机反馈修复。

## 改动

1. **到达终点动画增加 OK 按钮**：目的地到达（格子旗 + 里程/时间统计）原本 7 秒后自动消失、且点屏任意处即结束，停留时间太短来不及看清。现在画面常驻，下方出现一枚呼吸描边的 **OK** 胶囊按钮，**必须手动点 OK 才结束**，回到原来的界面。
2. **途经点（WAYPOINT）行为不变**：短版 3 秒庆祝仍点屏即关，保持轻量反馈。

## 行为细节

- 目的地到达：庆祝动画 + 行程统计常驻显示，OK 按钮在统计出现后（约 0.9s）淡入并带呼吸描边提示；触摸落在 OK 按钮矩形内才结束，点其他位置画面继续停留。
- 断连保护仍在：手机断开（含 `#OFF` 离线）时特效照常清除，避免卡在特效无法回到待机页。
- 途经点 `#J` 沿用原 3 秒自动消失 + 点屏即关。

## 刷机

- 资产 `MotoNav_universal_1.75_v7.12.10-ui.2-zelda40.3_panel0_app_0x10000.bin` 刷到 `0x10000`，不擦 NVS（时钟/设置保留）。
- 整包 `full_0x0.bin` 从 `0x0` 刷入。

## 注意

- 需要 iOS 客户端 **v0.15.8-zelda40.5** 配合（断开即时离线 `#OFF` 在 zelda40.2 已生效）。

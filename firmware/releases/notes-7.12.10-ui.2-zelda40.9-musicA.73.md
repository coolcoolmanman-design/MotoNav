# 固件 7.12.10-ui.2-zelda40.9-musicA.73

基线 musicA.72 / iOS 0.16.2.66。**固件 + iOS 双端同包**，配套 IPA **0.16.2.67**。
本版落地两份已确认的设计稿：FO-220 像素城市夜/昼双主题、FO-221 GrokBot 屏保表情包扩充。
安卓端本版不改。两份 release 保持 draft，不 publish。

## FO-220 · 动态背景：夜景改弦月 + 新增「像素白天」

确认稿 `pixel-city-daynight-compare.png`（A 夜景 / B 白天）。固件侧全部在 `DynamicBg.h::dynBgRenderPixelCity()` 内按 `day` 分支完成，仍然是 78×78 调色板网格 × cell6、零资源、零 BLE。

### ① style 6「像素夜景」：暖黄满圆 → 冷白弦月

用户反馈原来那个暖黄圆盘「像太阳」。现在同一位置 `(47,27)` 改成冷白弦月：

- 亮盘 `dbgRGB(0xE8,0xF1,0xFA)`，右上偏移 `(mx+2.6, my-1.5)` 挖一个 r4.3 的盘，留下左下 C 形；挖空处回填**该行天空色**（不是纯黑），所以月牙边缘不会发脏。
- 外圈 r4.6~6.8 用 `((x*7 + y*13) & 3) == 0` 的稀疏点做淡蓝光晕，两个环形坑、两颗伴星。
- 新增 `pxDiscF(float cx, float cy, float r, c)` 浮点半径圆盘（原 `pxDisc` 只接 int 半径，用于骑手轮子）。
- 星点、霓虹呼吸、金色滚动虚线、骑手 bob / 尾气 / 轮辐、速度线全部保持 musicA.71 上板的样子，动画节奏不变。

### ② 新增 style 7「像素白天」：同构图的另一半

不是另画一张：两版共用同一组 LCG 序列（`pxSeed=3` 的楼群、`pxSeed=11` 的夜星）和同一组相位（`ph`/`frame`/`scroll`/`spoke`），所以楼群轮廓、道路、骑手位置在 4 个动态帧里逐帧一一对应——是「同一个城市的夜与昼」。

| 元素 | style 6 夜 | style 7 昼 |
|---|---|---|
| 天空 | 4 段深蓝 `0x08..0x1E` | 4 段 `0x1E4A74 → 0x9BCEE7`，噪点阈值 30→18 |
| 天体 | 冷白弦月 + 星 + 伴星 | 暖黄太阳 + 8 向呼吸日芒 + 3 朵飘云（11 相位） |
| 楼群 | 深蓝剪影 + 霓虹灯窗 | 灰蓝楼体 + 顶部亮边 + 冷白玻璃反光 |
| 招牌 | 霓虹三色呼吸 | 遮阳棚 / 广告牌三色（同相位） |
| 路面 | 深蓝沥青 + 金色虚线 | 暖灰沥青 + 白色虚线（同一 8 相位） |
| 骑手 | 粉车 / 绿骑手 | 红车 / 绿骑手 + 白天专属高光 |

**刻意取舍**：白天版上半部天空保留中深蓝。固件待机页文字固定白色，做成通亮晴空后大时钟 `16:03` 和左右槽会读不清；若以后要「大晴空」，需同步把时钟/槽位字色改深色，那是另一套改法。飘云位置也全部避开大时钟区 `(gx13..65, gy6..23)`、顶部电量图标与左右槽文字。

### ③ 协议与 App

- `#BG,<on>,<style>,<speed>,<auto>` 的 style 上限 `0..6` 放宽到 **`0..7`**（`CommandReceiver.h`）；`DeviceContext.h` 注释同步。
- `dynBgRenderFrame()` 现在是 `if (style == 6 || style == 7) dynBgRenderPixelCity(t, style == 7)`；辉光类 1..5 仍走 117×117 Q15 路径且始终深色，**昼夜自动没有启用**，7 是手动选择的独立主题。
- App `Settings.swift::dynBgNames` 加第 8 项「像素白天」（index 7）；`DeviceHomeViews.swift` 文案改为「8 种风格」并写清 6/7 是同构图两主题；右上 84px 预览圆屏 `styleOverlay` 新增 case 7（亮青蓝渐变 + 太阳日芒 + 飘云 + 灰蓝楼群 + 白虚线），case 6 的暖黄满圆同步改成冷白月牙。

## FO-221 · 屏保：GrokBot 表情包 4 档睡意 → 16 表情 + 8 动效

现状（`musicA.24` 起）是纯黑底 + 一对白色竖胶囊眼，所谓「表情」只是 4 档睡意把同一眼型压扁，动画全是线性缓动的呼吸、扫视、点头。参考 xAI《Designing Grok Bot》六态动效与 `nasawz/GrokBot`（25 眼型 / 39 状态 / 阻尼弹簧形变 / 球面转头），全部改成参数化绘制。

### ① 16 种眼型（`SV_EXPRS[16]`，一个 `w/h/rot/dyL/dyR/kind/deco/scale/lid` 结构体表）

平静 / 好奇 / 开心 / 眨眼 / 得意 / 兴奋 / 震惊 / 疑惑 / 怀疑 / 爱心眼 / 晕眩 / 困倦 / 半睡 / 睡熟 / 惊跳 / 等待。

- 5 种眼型：`SVK_CAPSULE`（原竖胶囊）、`SVK_LINE`（横线，睡熟 / 等待）、`SVK_ARC`（上弯笑眼，白圆角矩形减上方黑块）、`SVK_HEART`（双圆 + 三角）、`SVK_SPIRAL`（三段极坐标弧）。
- 9 种装饰：`Zzz` / 三颗小心 / 汗滴 / 斜眉 / 两眼外侧闪线 / 三点脉动 / 感叹号 / 扁轨道 + 亮点 / 头顶三条尾迹。
- 设计稿里 5~9° 的逐眼旋转在固件里折成**两眼高低差**（歪头），视觉等价、零额外绘制开销，也不破坏「眨眼时底边固定」的语义。
- 所有装饰坐标都收在原有脏矩形 **74..392 / 132..300** 内；`svDrawEye()` 新增越界 clamp，极端组合（惊跳放大 + 满偏头转 + 4px 漂移）会把整只眼推进框内，而不是让局部推送把眼尾切掉。**脏矩形没有扩大，帧率来源不变**。

### ② 8 组动作

| # | 动作 | 实现 |
|---|---|---|
| 1 | 弹簧形变 | `svMorph` 阻尼弹簧 ω≈7 / ζ≈0.6，跨 0.5 才换脸，`morphScale` 先挤压再轻微过冲弹出 |
| 2 | 眨眼 / 单眼眨 | 95/30/155ms 三段（42% 闭 / 58% 开）+ 清醒时 5% 概率单眼眨 |
| 3 | 球面转头 + 尾迹 | `turn = sin(e·π)·1.35`，`cos` 压缩眼距/眼宽、横向位移 34px，头顶三条渐变尾迹 |
| 4 | 三点脉动 | 眼睛暂时退场，1.4s 相位差 1/3 的三点（思考 / 等待） |
| 5 | 轨道环绕 | 4s 扁椭圆轨道 + 一颗亮点绕行 |
| 6 | 惊跳 + 拖尾 | IMU 猛晃触发 0.7s 放大、双眨、感叹号 + 尾迹 |
| 7 | 打盹点头 | `svState==3` 点头幅度 0.55→0.85，约 15s 一次 |
| 8 | 表情池漂移 | 清醒时 9~16s 随机换一张脸，避免长时间定格 |

决策只用屏保本来就能可靠读到的全局量，不新增任何协议：**IMU 惊跳 > 连续甩动晕眩 > 睡意三档 > 无手机连接时加权「等待」> 表情池**。动效每 18~30s 抽一段，与常驻的弹簧/眨眼/点头/漂移叠加。

**按用户要求不加 App 特效开关**：`saverEnabled` / `#SV` 总开关维持原样，选上屏保即自动获得整套表情；`CommandReceiver.h` 里 `#SV` 处理一行未改。也没有引入 GrokBot 的彩色 blob 身体——AMOLED 长期点亮大面积彩色既烧屏又破坏 45% 亮度对比，新特效全是中灰小面积，且都落在原脏矩形内。零位图、零额外 Flash 资源。

### ③ 保留不动

45% 亮度 + 40~120 夹紧 + 320ms 渐变、4px / 180s 防烧屏漂移、IMU 四层互动（重力跟随 / 惊跳 / 陀螺惯性 / 睡意）、30fps 目标、触摸只唤醒、进入后前三次帧率日志。日志扩展为 `[SAVER] fps=.. state=.. expr=.. motion=..`，并新增低频 `[SAVER] expr=N -> M` / `motion=N` 便于实机定位。

## 编译与体积

本地 `python firmware/build.py --cli ... --jobs 8`：**Flash 2,944,327 B（93%）/ RAM 144,844 B（44%）**。
相对 musicA.72（2,938,887 B）只增约 5.4 KB —— 两块新内容都是代码而非帧资源，Flash 余量仍约 200 KB。

## 建议实机验证

1. 圆屏停在**待机首页**（中央=动画、非全屏表盘），App 动态背景选「像素夜景」：确认右上角是**冷白月牙**而非暖黄圆盘；抓日志看 `[BG] on=1 style=6 ... active=1 buf=1`。
2. 改选第 8 项「像素白天」：确认太阳 + 日芒 + 飘云 + 灰蓝楼群 + 白色虚线，大时钟/左右槽白字仍清晰；回执应为 `BG,1,7,18,0`。切回 1..5 辉光类与路口图不受影响。
3. 静置 60s 进屏保：观察 9~16s 换一次表情、18~30s 抽一段动效；眨眼/点头/转头尾迹/三点脉动/轨道都能看到；敲一下桌子触发惊跳；连续甩动出晕眩；静置 90s/3min/5min 依次出困倦/半睡/睡熟。
4. 抓开机日志确认 `[SAVER] enter ... expr=16 motion=8` 与三次 `fps=` 仍 ≥30；退出屏保亮度淡回、触摸不产生手势。
5. 确认 App 设置页**没有多出任何开关**，只有原来的「屏幕保护」总开关。

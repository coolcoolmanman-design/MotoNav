# MotoNav 通用固件 7.12.9-ui.3 · PWR 键短按息屏

基于 7.12.9-ui.2 源码迭代，由 CI 从源码构建。1.75 圆屏（Waveshare ESP32-S3-Touch-AMOLED-1.75 / AXP2101）通用。

## 新功能

| 操作 | 行为 |
|---|---|
| 长按 PWR | 关机（AXP2101 硬件行为，与之前版本一致，不变） |
| 短按 PWR（接电 / USB 供电时） | **息屏**：AMOLED 彻底灭屏（displayOff），BLE 与导航数据接收不受影响 |
| 短按 PWR（息屏状态） | 亮屏，恢复息屏前的亮度（手机端调过的亮度也记得） |
| 短按 PWR（电池供电时） | 不动作（防止骑行颠簸误触息屏） |

## 实现说明

- 短按事件来自 AXP2101 的 PEKEY 中断状态位（STATUS2 `0x49` bit3，写 1 清除），使能位 ENABLE2 `0x41` bit3；主循环轮询，无新增任务。
- 息屏走 `displayOff()`（与闲置关机同款灭屏方式），亮屏 `displayOn()` + 恢复亮度；亮度调节命令（`#b`）与息屏状态互不干扰。
- 手动息屏 / 亮屏会重置 5 分钟闲置关机计时，避免两个机制打架。
- 电池供电下若已息屏（比如息屏后拔了电），短按仍可亮屏，不会把屏锁死。

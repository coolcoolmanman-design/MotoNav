# Firmware v7.12.10-ui.2-zelda40 · 塞尔达40周年特别版

基于 v7.12.10-ui.2（含上游 IPC 任务栈守卫）的纪念版固件，版本号不占 ui 序列。

## 新增：开机动画「塞尔达40周年旗帜」

- 开机 6.8 秒动画（品牌 ID 17 `ZELDA40`，默认启用；用户改过开机品牌设置则沿用其设置，可在客户端开机画面设置里改回）
  - 0–3.8s：以旗帜"40"字样中心为原点，整幅画面从暗到亮向外扩散（150px 软过渡亮度波）
  - 3.8–6.8s：旗帜边框滚动流光——白热光头带金色拖尾沿旗框巡游循环
- 开机背景为整幅纪念旗照片构图（含暗金三角纹理底），资源为 466×466 RGB565 位图，运行时只做亮度与流光合成，无逐帧资源

## 修改：待机页（首页）

- 背景替换为暗金三角纹理（466×466 RGB565），全部局部擦除改为纹理恢复，不再擦黑
- 待机时钟、日期、天气文字改为金黄色主题
- 像素女骑手替换为塞尔达 40 周年像素场景（3px 放大网格精灵）：
  - 在线（ready）：林克单手抱塞尔达骑兽形摩托，大师之剑举/挥两帧循环，车身悬浮、车尾尾气、风线刮过
  - 离线（no link）：故障摩托冒白烟，林克躺在塞尔达怀里休眠，ZZZ 漂浮
  - 蓝牙断连（LINK LOST）：保持红色提示环

## 兼容性

- 开机品牌协议新增稳定 ID 17，`#b,` 命令与客户端开机画面设置同步兼容（旧客户端仍可设置 0–16）
- 其余功能与 v7.12.10-ui.2 完全一致

## 刷机

- app 镜像写入 0x10000（不擦 NVS，保留时钟/设置）；SHA256SUMS 见资产

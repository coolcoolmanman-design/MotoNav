# MotoNav 固件 musicA.93 · 体育场动态重做 + 申花帧降红

> 配套 iOS **0.16.2.85**（本版无需 App 升级）。基线 musicA.92。**musicA.84 仍不安全，勿刷。** Draft 保持。

## 本版

- **动态背景 style 8「申花体育场」黑块修复 + 动态重做：**
  - 根因：体育场资源是圆形构图，圆外约 21.8% 为 `chroma 0` 透明。musicA.92 的「下半屏整行 wrap 滚动」会把圆两侧的透明块卷进可视圆内，形成黑色空缺。
  - 修复：去掉整行 wrap 滚动，改为三处**只在圆内绘制**的轻量动态（仿 style 7 像素白天的克制风格）：
    1. 天空飘云：3 朵圆润像素云在 y<130 缓慢横移，避开中部大时钟区；
    2. 看台闪光灯：y148~252 稀疏暖白点按相位闪烁；
    3. 草坪柔光横扫：y285~452 一道柔和亮带缓慢扫过。
  - 三处动态每帧都从静态 still 重新铺底、不累积；圆外透明区完全不参与运算，黑块彻底消除。资源本身未改。
  - 不涉及 NVS / 命令协议：App 原样下发 `#BG,<on>,8,<speed>,0` 即可。
- **中央动画（待连接 / 已连接）色调修正：** 针对用户反馈「两套动画偏红」，对两套参考图帧做温和降红重配（B 档：红色 sat×0.78 / val×0.90，蓝色 sat×1.06 / val×1.05）。红衣回到正常红色系、蓝色摩托与球衣更干净。帧尺寸 189×135 / 8 帧 / 3500·2400 ms / `chroma 0` 透明全部不变。

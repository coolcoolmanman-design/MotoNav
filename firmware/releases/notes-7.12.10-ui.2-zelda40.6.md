# MotoNav 固件 v7.12.10-ui.2-zelda40.6（塞尔达40周年特别版）

## 修复：目的地到达动画被「自动关闭」

**现象**：zelda40.3 起目的地（到达终点）动画改为「常驻 + 手动点 OK 才关」，但实测中还没点 OK，约 7 秒后画面就自动消失了。

**根因**：目的地动画的关闭条件里保留了两条「自动抢关」逻辑，与「常驻等 OK」的设计冲突：
1. `MotoNav.ino` 主循环：`fxOn && ((!fxManual && 超时) || !conn)` —— 途经点（fxManual=false）断连才关本属正常，但写法让目的地一旦遇到 `!conn`（手机 App 到达后结束导航 / 发 `#OFF` / 蓝牙断开）也被立即关掉。
2. `CommandReceiver.h`：App 在动画期间发来新的非「A」导航方向（`navDir != "A" && fxOn`）会直接 `stopArriveFx()`，把目的地庆祝画面顶掉。

**改动**（行为与画面不变，仅关闭时机修正）：
- `MotoNav.ino`：目的地到达（`fxManual`）**豁免**断连 / 超时自动关闭，只保留「点 OK 关闭」+ 60 秒安全兜底（防止极端情况下画面卡死）；途经点维持原行为（超时或断连即关）。
- `CommandReceiver.h`：目的地到达期间，App 发新导航方向不再抢占关闭，仍等用户点 OK。

**预期**：到达终点后，庆祝动画 + 行程统计 + OK 按钮常驻显示，直到手动点 OK 才结束；手机断连、结束导航、重新规划路线都不会把它顶掉（仍有 60 秒兜底防卡死）。

## 验证
- CI 构建通过，已刷 COM5 实测。
- 请到车/到目的地后实机触发 `A,0` 到达：确认画面停留到你点 OK，且期间断开手机 App 也不消失。

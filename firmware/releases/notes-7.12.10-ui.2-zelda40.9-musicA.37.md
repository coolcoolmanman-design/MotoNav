## 一、预设动态背景（6 风格 × 昼夜 × 漂移加速）

新增 `src/graphics/DynamicBg.h`，纯程序化逐帧渲染，**零 BLE 传输、零文件存储**：

- 6 风格：`0 现有静态 / 1 呼吸金纹 / 2 流动极光 / 3 星尘粒子 / 4 斜向光扫 / 5 同心涟漪`，共用同一帧缓冲 `dynBgBuf`（PSRAM 466×466 RGB565）。
- 漂移统一 `T = millis() × dynBgSpeed/10`，默认 ×1.8（可调 1.0~2.6），**只缩放时间不改幅度**。加快后周期：呼吸 3.2s / 极光 8.3s / 星尘 9.9s / 光扫 6.2s / 涟漪 3.5s。
- 昼夜两套映射：夜间深底 `screen` 辉光（暖金 + 冷蓝 + 紫），白天浅底 `multiply` 暗纹（额外提对比）。直接读全局 `nightOn`（App 的 `#n`），不新增定时器；`#n` 变化会触发整页重绘。`dynBgAuto=0` 时锁定白天。
- 性能：466² 逐像素浮点太重，改成 **117×117 低分辨率网格（每格 4×4 像素）+ Q15 定点 + 256 项正弦表**，每帧只算 1.37 万个网格点；星尘的锐利星点在网格之后叠到全分辨率缓冲。10fps 下再整屏 `zbgRect()` 恢复一次，与 `animateCat()` 的 100ms 一拍同频。
- **上传自定义壁纸 > 动态背景**：`bgCustomOn` 为真时 `dynBgActive()` 自动为假，动态帧暂停但已选风格保留；`#BGD` / App「恢复默认」清掉自定义图后自动续上，不需要额外命令。

新命令 `#BG,<on>,<style 0..5>,<speed 10..26>,<autoDayNight>`，NVS 存 `bg_on / bg_sty / bg_spd / bg_auto`，回执 `BG,...`。
开机默认 `bg_on=false`（刷机后没连 App 时仍保持原有透明黑观感），App 一连上即同步。

## 二、六槽改造：上方槽 / 中央槽 / 9 种时间样式 / 全屏指针表盘

新增 `src/pages/ClockStyles.h`：

- **上方槽**（y36–134）5 功能：`0 时间`（完全沿用原日期行 + size10 大时钟）、`1 速度`、`2 实时G`、`3 胎压`、`4 天气`；除时间外放大到 size 8、单位/标签下移一行。
- **中央槽**（136–360）3 功能：`0 中央动画`（原逻辑，`#FV` 载具不变）、`1 时间`（9 样式）、`2 全屏指针表盘`。
- **9 种时间样式**：0 现有像素数字 / 1 石英极简大数字 / 2 G-Shock 七段电子 / 3 潮流纵向排列 / 4 LED 点阵 / 5 石英三针 / 6 包豪斯几何 / 7 月相机械 / 8 数字指针混合。都含时间与日期，配色随 `nightOn` 切昼夜；七段与点阵自带字模表。
- **全屏指针表盘**：复用 `SEC_RING_R=222` 刻度函数、`thickLine()` 画细长表针、`aaDisc()` 轴心、剑形针尖（针尖往回 20px、垂直偏移 ±线宽，不再是上一版效果图里的大三角）。样式取 5–8 四种，盘面仍留小号数字时间 + 日期窗（纯指针骑行不易秒读）。A 纯净（5 槽全让位，默认）/ B 四象限外环微读数（速度 / 实时G / 胎压 / 天气，指针缩到 90%）。
  - 只在 `onWaitScreen && !inNav` 生效，进入导航 / 路口放大图 / 来电页自动让位。
  - `animateCat()` 里整屏重画后**直接短路返回**，避免每拍 `zbgRect(0,BAND_Y0,466,BAND_H)` 把表盘下半部擦掉。
  - 静态背景下只在秒针跳格时重画（1fps）；开了动态背景才每拍刷新（10fps）。

新命令 `#FC3,<top>,<center>,<style>,<ab>`，NVS 存 `fc3_top / fc3_ctr / fc3_sty / fc3_ab`，回执 `FC3,...`。
**旧 `#FC2` 一字不改**：老固件忽略未知命令天然兼容；老 App 连新固件时四个新字段全取默认值（时间 / 中央动画 / 样式 0），观感与升级前完全一致。

## 三、秒针刻度与红点分离（用户拍板规则）

原「大时钟 + 60 格刻度环 + 每秒红点」共用 `slotMask bit0`。现在拆成两个条件：

| 盘面状态 | 60 格刻度 | 每秒红点 |
|---|---|---|
| 上方槽 = 时间 | ✓ | ✓ |
| 中央槽 = 时间（上方槽非时间） | ✓ | ✗ |
| 中央槽 = 全屏指针表盘 | ✓ | ✗ |
| 两槽都不是时间 | ✗ | ✗ |

- `hasTimeFace() = (top==0)||(center==1)||(center==2)` 管 `drawRingTicks()`；`dotOn() = slotMask bit0` 严格只管红点。
- App 的 `faceCfgMask` bit0 由 `topFunc==0` 推导，固件 `#FC3` 收到后也会修正 bit0，所以把上方槽从时间切到速度时，大时钟和红点会一起消失，不会「赖着不走」。
- 全屏表盘自绘静态刻度，**不依赖 `drawSecondRing()` 的显示门控**（全屏下上方槽让位 + `animateCat()` 短路，没人调它）。
- 从「有时间」切到「都不是时间」时主动逐格 `zbgRect()` 恢复上下边缘，避免残留一圈灰点。

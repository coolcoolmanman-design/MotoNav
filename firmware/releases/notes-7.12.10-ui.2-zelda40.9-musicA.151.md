# musicA.151（配 iOS 0.16.2.135）

按实机照片与参考营销图的逐项对比，修正样式 16「昼夜通透」的 7 处差距，并修复
「地图源已切天地图、底图正常，但圆屏瓦片仍时不时消失」。

## 1. 瓦片时不时消失（天地图源，底图正常）

上一版（.150）只放宽了 `rasStickyOK` 的 6h 时间窗，但还有两道帧号门闸会把瓦片整块切走：

- `rasFrameOK` 要求 `rasterFrame == posFrame`。天地图 HTTP 底图的帧号来自 App 截图批次，
  和手机 GPS 定位帧号 `posFrame` **不是同一序号**——只要对不上，sticky 就形同虚设。
  → 样式 16 不再要求帧号相等，只要在 6h 窗内就一直铺。
- `useRaster` 还有 `!vecOK || rasterAt >= vectorAt` 的竞争条件。样式 16 本不发路网包，
  但上一次导航残留的 `mapValid` 会让 `vecOK` 误判为真，把底图顶掉。
  → 样式 16 直接 `useRaster = rasOK`，不与路网竞争。

## 2. 右侧半弧线（参考稿有、实机功能缺失）

右外圈补一条与左倒计弧镜像对称的弧（R216.5、头端 +21.5°、顺时针 125°）：
暗色底弧常显，已完成段绿色（`0x26E8`），当前位置一个白点。
数据取固件现成的行程进度 `tripFrac()`（已走 / 总里程），无需 App 新增下发。

## 3. 导航箭头形状

实机是细 V 形双线尖角，参考稿是**实心三角箭头头**。
笔画 11→12、三角头长 28 / 半宽 22，保留圆角肘 + 竖杆底端圆头 + 真羽化软投影。

## 4. 中央散乱小图标

实机中央堆了一圈 GPS 弱信号圈、测速牌、电子眼类型图标，参考稿这里只有路线上的红绿灯。
样式 16 现在屏蔽 `drawMapCams()` / `drawCamIcons()` 与 GPS 弱信号提示，
保留 `drawMapLights()`（红绿灯）。

## 5. 路名与底部胶囊重叠

实机「真北路」压在「30分 · 12.5km」胶囊上。路名中心从 y370 上移到 **y352**，
与胶囊上沿 y381 留 11px 间隙。

## 6. 车速 / 限速 / 车道图标

- 右侧红徽由「剩余分钟数字」改回参考稿的**白色测速摄像头图标**（深红底 + 浅红描边），
  无电子眼时才回退显示分钟。
- 限速白盘红环（`(379.5,297.5)` 白盘 r18.5 / 红环 r22.5）保持不变；有测速数据时显示。
- 车道四格改为**常显**（此前只在 `ringActive` 倒计时期间画，实机整段看不到车道）；
  推荐胶囊色昼 `(6,48,62)` / 夜 `(2,40,53)` + 浅灰蓝描边。

## 7. 上下黑色阴影过大

参考营销图的上下压暗没那么重：顶部峰值 250→185、范围 172→150；
底部线性加深 225→150。仍保留 0.6 次幂曲线，白字在亮地图上依旧可读。

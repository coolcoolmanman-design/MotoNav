# MotoNav firmware musicA.160

配套 iOS：**0.16.2.136**（无需升级）

## 相对 .159 的变更

### 倒计弧按参考 App 的实拍视频重定位置

`.159` 把设计稿营销图当成了实际 UI，做成「从左侧绕过顶部一直拉到右下 4 点」的 218° 长弧。实拍视频逐帧量出来的真实位置完全不同：

| 项 | .159 | .160（视频实测） |
|---|---|---|
| 头端（红点） | +118°（右下 4:00） | **−140°（左下 8:00）** |
| 尾端 | −100°（左下 8:00） | **−78°（9:15）** |
| 满长 | 218° | **62°** |
| 位置 | 绕顶部横跨半圈 | **只在屏幕左下** |

测量方法：视频 2160×3840 / 60fps，抽 12 帧（0.1s~5.9s），每帧先拟合屏幕圆（残差 15~24px），再沿边缘内侧逐角度扫青色像素。12 帧结果稳定在两段 **−142°±1** 与 **−77°±1**，中间 −141°~−102° 被红点与边缘暗角遮断，故实际是一段连续弧。

红点在弧的下端（−140°），直径约 10px（对应 466 屏），倒计时收短时尾端向下端收，流光方向不变。

### 参数位置

`dnGlassCountRing()` 里只有两个数要改：

```cpp
const float R = 216.5f, A1 = -140.0f, MAXL = 62.0f;
```

`A1` 是头端（红点）角度，`MAXL` 是满长跨度。要回到设计稿那种长弧，只把 `MAXL` 调大、`A1` 改正值即可。

## 刷机

```
esptool --chip esp32s3 --port COM5 --baud 921600 --before default_reset --after watchdog_reset \
  write_flash 0x8000 <partitions_0x8000.bin> 0x10000 <app.bin>
```

**不要**写 `full_0x0.bin`。

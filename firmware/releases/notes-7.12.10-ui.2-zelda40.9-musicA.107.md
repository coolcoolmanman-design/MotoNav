# musicA.107

## 变更

### 中央动画色彩修正（修复 .106 发淡问题）

- 两套新中央动画（待机打斗 / 连接态冲刺）重新烘焙，修复 .106 版本色彩偏淡：
  - **调色板只统计不透明像素**：.106 的 16 色调色板被画布上的白烟尘与透明黑区稀释，
    蓝色球衣 / 红衣等饱和色分到的色阶过少；.107 改为 32 色共用调色板、
    仅对 alpha≥128 的像素统计，量化饱和度比源图 +10%。
  - **预乘 alpha 缩放**：LANCZOS 直通缩放会让边缘与透明黑混合导致发灰；
    .107 采用预乘缩放后反预乘，边缘颜色与源图一致。
- 量化实测：饱和度比 = 1.10（idle）/ 1.10（conn），亮度比 0.96 / 0.97，观感鲜亮自然。
- zlib 体积 idle 49,308B / conn 60,014B（.106 为 38KB / 45KB），4MB 槽内余量充足。
- 其余内容与 .106 完全一致：动画尺寸 189×135 / 8 帧 / 帧时序不变、闲置 5 分钟
  自动关机开关（#IDLEOFF + NVS，默认开）不变。

## 刷机

- 分区表 + app 一起刷：`0x8000` 分区表、`0x10000` app，不要刷 `full_0x0.bin`（会抹 NVS）。
- app 槽上限 4MB（4,194,304B），刷前核对 manifest SHA256。

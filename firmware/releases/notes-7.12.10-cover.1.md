# 固件 v7.12.10-cover.1 — 音乐封面（通用，iOS + 安卓）

相对 v7.12.10-ui.2：音乐页支持显示专辑封面圆盘，兼容 iOS 与安卓客户端。

| 项 | 改动 |
|----|------|
| 固件 | 新增 bulk type 5（音乐封面）：接收 `'CVR'` 头 + zlib RGB565 方图，tinfl 解码进 PSRAM；音乐页收到封面改为圆盘布局（r=64 圆盘居上，歌名/歌手/按钮下移；无封面保持原布局，歌词在封面布局下暂不显示） |
| iOS | 新增 `CoverBridge.swift`：App 模式直读 `nowPlayingItem.artwork`；HID 模式先本地曲库匹配（标题+歌手），失败走 iTunes 搜索 API 兜底（artworkUrl100→600x600bb）；居中裁方 128×128 → RGB565 → zlib → bulk type 5 |
| 安卓 | 新增 `CoverBridge.kt`：MediaSession 直读 `ALBUM_ART` 位图或 `ALBUM_ART_URI`，同样编码发送；无需 iTunes 兜底 |
| 带宽 | 128×128 RGB565 zlib 后约 15~25KB，BLE @~12KB/s 约 1.5~2s/首，仅切歌时传输，与地图流共存（走同一 bulk 队列优先级） |

## 试法

1. 烧录本固件，安装配套 iOS（≥0.15.16）或安卓客户端
2. 手机播放任意歌曲（网易云/QQ 音乐/Apple Music 均可），滑到音乐页
3. 切歌后约 2 秒封面出现（首首冷启动含网络拉取会略慢）
4. 对照：安卓不发封面的旧版本仍显示原 MUSIC 布局（向后兼容）

## 说明

- 封面来源在 HID 模式下 iOS 无公开 API 读第三方播放器，本地曲库 + iTunes 兜底命中率主流歌曲很高；安卓端 MediaSession 直出位图，无此限制
- 圆盘为固件端逐行圆形裁剪渲染，手机发方形图即可
- 封面按「标题|歌手」缓存于手机内存，不落盘

## 脱敏说明

- 本说明与代码不含高德 Key、账号、设备序列号、私人路径
- iTunes 搜索请求仅含歌曲名与歌手名，无用户标识

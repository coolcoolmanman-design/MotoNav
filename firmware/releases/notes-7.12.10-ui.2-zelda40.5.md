# MotoNav 固件 v7.12.10-ui.2-zelda40.5（塞尔达40周年特别版·修订5）

## 改动
- **修复塞尔达40周年开机动画「淡入掉帧」**：开机前 1.4s 淡入期从暗到亮只能看到 2–3 帧，明显不流畅；但之后的旗框滚动流光（约 1400ms 之后）正常。
- **根因**：`helperInit()` 把「另一核心帮忙画底图」的 helper 任务钉在**核心 0**（与刷屏 `flushTask` 同核，且优先级 3 > flush 的 2）。开机头 ~1.4s 该 helper 在做初始底图绘制，把核心 0 的刷屏任务饿死，导致淡入期每一次 `flushSync()`（等整帧推到屏）被拖到 ~250ms，整段淡入只出了 2–3 帧。等 helper 干完活（恰好 ≈ 流光开始时刻），刷屏才顺畅。
- **修复方式**（画面、时长、配色完全不变）：
  1. 将 `helperInit()` 从开机初始化段（动画之前）**移到开机动画结束之后**执行，开机期间核心 0 完全让给刷屏任务。helper 的初始底图绘制延后约 3s 发生，此时已进入等待页 / BLE 初始化阶段，不影响动画。
  2. 在开机动画循环前增加**一次黑屏预热 `flushSync()`**，吸收一次性 SPI / QIO 建立开销，避免淡入首帧被拖慢。
- 与 zelda40.4 的渲染查表优化（距离/角度 LUT + 整屏背景缓存）叠加后：淡入与流光两阶段均运行在「核心 0 专供刷屏」的顺畅区间，预期淡入从 ~2–3 帧提升至 ~25–30fps。

## 注意事项
- 仅调整任务调度时序，未改动任何绘制逻辑、动画参数（`ZELDA_BOOT_FADE_MS=1400`、`ZELDA_BOOT_TOTAL_MS=3000` 不变）。
- helper 延后启动约 3s，对进入导航页前的使用无影响。

# MotoNav 固件 musicA.92 · 申花新帧 + 体育场背景修复

> 配套 iOS **0.16.2.85**（本版无需 App 升级）。基线 musicA.91。**musicA.84 仍不安全，勿刷。** Draft 保持。

## 本版

- **中央动画（待连接 / 已连接）：** 按用户确认的精灵表参考图重做两套 189×135 帧。
  - 待连接 IDLE：蓝衣少年奔跑 / 出拳 / 踢飞红衣对手 → 倒地烟尘（上排 8 帧，3500 ms / 437 ms 每帧）。
  - 已连接 CONNECTED：骑蓝色摩托加速、速度线渐强 → 撞倒红衣、白烟（下排 8 帧，2400 ms / 300 ms 每帧）。
  - 抠掉棋盘格伪透明背景，统一窗口等比缩放，整套共用 16 色调色板 + RGB565，`chroma 0` 透明；帧尺寸 / 帧数 / 时长 / 命令协议不变。
- **动态背景 style 8「申花体育场」修复：** 原 `dynBgRenderStadium()` 给 `inflateZlibRgb565()` 传的 `need` 是**像素数**（156×156），而该函数要求**字节数**（其余调用点都传 `W*H*2`）。结果解压永远失败 → `stadiumReady` 一直 false → 每帧直接 return，圆屏选「申花体育场」后背景不生效。已改为传 `need*2`，解压一次成功，随后整屏最近邻放大 + 草坪带轻滚动正常渲染。
  - 不涉及 NVS / 命令协议：App 原样下发 `#BG,<on>,8,<speed>,0` 即可生效。

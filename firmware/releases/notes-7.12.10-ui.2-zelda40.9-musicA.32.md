# MotoNav 固件 7.12.10-ui.2-zelda40.9-musicA.32

配套 iOS：**0.16.2.31**（必须一起升级，见文末兼容性）

## 一、路口图跟昼夜主题成套（修复「永久夜间」）

固件一直有两套地图配色 `THEMES` / `THEMES_NIGHT`，由 App 按日出日落发 `#n,1/0` 切换；
但路口放大图完全绕开了这套机制：

- App 侧 `CrossImageSender.swift` 固定做灰阶反相 + 深底 `(26,31,39)`；
- 固件侧 `crossBlitFrame()` 的两层投影和描边 `0x1082 / 0x18C3 / 0x52AA` 也是写死的深色。

结果白天手机是浅色地图、圆屏底图是白天主题，中间却贴着一块夜间深色浮窗。

现在：

- App 按 `paletteNight` 出两套调色板（夜间反相深底 / 白天浅底深线），
  **调色板随包下发，固件解码不用动**；昼夜切换时自动把当前路口图重发一遍。
- 固件 `crossBlitFrame()` 的描边按 `nightOn` 切：夜间 `0x52AA` 青绿细边，白天 `0x4208` 深灰细边。
- 彩色槽改为只取色差 ≥70 的高饱和像素均值，基本只剩引导路线；灰阶四档边界改为按本图实际亮度动态计算，
  不再用只为夜间反相写死的 `[20,55,85,115,161]`。

## 二、浮窗布局调整（参考竞品圆屏）

| | 旧 | 新 |
|---|---|---|
| 尺寸 | 272×174 | **272×150** |
| 上沿 / 下沿 | 72 / 246 | **96 / 246**（下沿不变，仍让开 `MAP_PY=262` 车头） |
| 比例 | 1.56:1 | 1.81:1（竞品约 1.78:1） |
| 圆角 | 18 | 6 |
| 外框 | 两层投影 + 垫边 + 描边 | **一条 1px 描边** |

- **修掉压字**：车速 `printOutlined(..., 44, size4)` 底边约到 74，旧窗口顶在 72，实机会压住数字底部。
  上沿下移 24px 后留足余量。
- **卡片变轻**：圆屏 + 橙色圆环 + 矢量底图视觉重量已经够，去掉双层投影后更像「地图上开的一扇窗」，
  白天浅底时尤其不抢戏。
- 预览同步改为 `136×75`（`CROSS_PH`），仍是全图 1/2、固件 2 倍最近邻放大。

## 三、串口怎么看

```
MotoNav ready, firmware v7.12.10-ui.2-zelda40.9-musicA.32
[CROSS] parse ok preview 136x75 ...
[CROSS] parse ok full 272x150 ...
[CROSS] overlay on (full ...)
```

若看到 `[CROSS] parse: 尺寸 272x174 不认识`，说明 **App 还是旧版**。

## 兼容性（重要）

- **尺寸两端同步**：固件 `MapState.h` 的 `CROSS_W/H/PW/PH` 与 iOS `CrossImageSender.W/H/PW/PH`
  必须一致，否则整包被丢弃。本版改了高度，**固件和 App 必须一起升级**。
- 只升固件、App 仍发 272×174 → 路口图不显示（有串口日志提示，其余功能正常）。
- 只升 App、固件仍认 272×174 → 同上。
- 协议仍是 `ver=2`（5 色 + nibble RLE），没有新增字段；Flash 占用 57%。

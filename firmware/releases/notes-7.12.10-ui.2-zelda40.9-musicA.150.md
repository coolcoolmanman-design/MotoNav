样式 16「昼夜通透」按参考稿（`_refd466.png` / `_refn466.png`，466×466）逐元素重做，

## 修：瓦片过一会儿就消失

根因是**锁屏/后台取不到底图**：样式 16 走高德 SDK 截图，而截图必须前台渲染。
一锁屏 `setRenderingAvailable(false)` 就取消在途任务，固件那边的瓦片虽被 sticky 保留，
但只要触发一次 `rasterCoversView()` 判定为不覆盖视口（车开出原图块），地图就整块变空，
而 App 再也补不上新块 —— 看起来就是「显示一会儿后消失」。

- 固件：样式 16 的 `rasStickyOK` 放宽为 `rasterValid && rasterAt 在 6 小时内`，
  不再因为视口算不满就丢瓦片；越界采样改走 `t3dIdxClamped()`（取最近边界像素，
  距离 ≥48px 或边界是楼块才回退地面），铺满到 `DN_MAP_R = 232` 时不会有黑边。
- iOS 0.16.2.135：新增 `lockscreenHttpFallback` —— 样式 15/16 + 高德源 + 非前台 + 有天地图 Key 时，
  底图改走天地图 `vec_w` HTTP（锁屏可取），按 `SRC_TDT` 存缓存、不污染高德缓存；
  回前台 `setRenderingAvailable(true)` 再自动补高德底图 + 建筑轮廓。
  没有天地图 Key 时胎压/地图提示会明确说明原因（`buildingInfo`）。

## 软掩膜：真羽化 + 真 alpha 混合

原来的 `drawGlyphShadow()` 把 8bit alpha 钳到 15 再交 4bit 混合，等于「硬黑边」。
新增 PSRAM 软掩膜模块（`VectorDrawing.h`：`smBegin / smBlur / smMix / smShadow / smCopy`，
6 个槽位，按内容哈希缓存）：

- 大数字 / 时间 / 单位 / 车速数字 / 中文路名 → 真羽化投影（偏移 + 半径 + 浓度可调）；
- 转向箭头 → 覆盖率掩膜 + 复制模糊（r=3）两遍，笔画细也不糊边；
- 中文路名 → `drawTextImgGlass()` 按 alpha 真混背景，不再是「白字直写 + 黑描边」。

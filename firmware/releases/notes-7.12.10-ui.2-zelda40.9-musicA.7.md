# MotoNav 通用圆屏固件 7.12.10-ui.2-zelda40.9-musicA.7

**基线：musicA.5**（秒环残影修复、封面最近邻旋转、chrome 条带——即昨天刷入的 untagged-243c298e596c4442345b 那稿），在其上叠加待机页可换表盘。

## 待机页可换表盘（一期 A：协议 + 渲染）

- 新增 `#FACE,<id>` 指令：手机「圆屏设置 → 表盘选择」选款后下发，固件存 NVS（键 `faceid`），回 `FACE,<id>` 确认；开机自动沿用，连接后 App 也会同步。
- 待机页背景源在「塞尔达纹理（`faceId<=1`）」与「程序化表盘（`faceId>=2`）」之间切换：`zbgRect` 统一从 `homeBg` 拷贝，切换只改 `homeBg` 指向，擦除/恢复逻辑全部跟随。
- 四款程序化表盘（几何风格，非 bitmap 渐变质感）：
  - `2` 极简黑：细灰环 + 中心点
  - `3` 赛博霓虹：放射线 + 霓虹同心环 + 旋转扫描线
  - `4` 机械：刻度表盘 + 秒针式指针
  - `5` 运动橙：速度表弧段 + 脉冲扩散环
- 表盘切换整页重绘（`faceDirty`），无需重启；时钟、秒环、连接态、天气等固定 UI 保持原样。
- 与 musicA.4 的秒环残影修复兼容：`drawSecondRing` 的 `zbgRect` 清残影在新表盘下自动恢复对应程序化背景。

## 配套 iOS

- 「圆屏设置 → 表盘选择」选择器与 `#FACE` 收发随 0.16.2.6-tpms 一稿 IPA 提供，无需更新。

## 刷机

- App 镜像烧 `0x10000`，整包烧 `0x0`；保留 NVS（不擦时钟/设置）。

# MotoNav 固件 7.12.10-ui.2-zelda40.9-musicA.17

## 六槽表盘重构（配合 iOS 0.16.2.17）

待机页从「背景 + 四槽」升级为「背景 + 六槽」，顶部电量不再占槽（恒显示，颜色仍可调）：

| 槽位 | 位置 | 显隐 | 颜色 | 说明 |
|------|------|------|------|------|
| 电量 | 顶部居中 | 恒显示 | 可调 | 与蓝牙点同组，不再受掩码 bit1 控制（#FC2 强制置 1） |
| 时间槽 | 上部居中 | 可开关（bit0） | 可调 | 日期 + 大像素时钟 + 秒针环（时钟上移 60..130） |
| 左上槽 | 左侧贴边 | 恒显示 | 可调 | 功能四选一：0 速度 / 1 G值 / 2 胎压 / 3 天气 |
| 右上槽 | 右侧贴边 | 恒显示 | 可调 | 同上（与左上互相独立） |
| 中央动画槽 | 中部 | 可开关（bit3） | 可调 | 塞尔达放大 cell 3→4（200×224）；载具可切换 |
| 下方槽 | 下部居中 | 恒显示 | 可调 | 功能四选一（同左上/右上） |
| 连接态槽 | 底部边缘 y420 | 可开关（bit2） | 可调 | ready / no link 小字；WAIT_LOST 时让位给 LINK LOST |

- 三槽功能/颜色/新显隐经 **#FC2,<tc>,<bc>,<cc>,<mk>,<f0>,<f1>,<f2>,<c0>,<c1>,<c2>,<cv>** 下发，NVS 持久化，回 ACK `FC2,…`。旧 `#FC` 保留兼容（旧 App 不受影响）。
- 中央动画载具 **#FV,<id>**：0 塞尔达×摩托（默认） / 1 像素小人×摩托（v4.6 旧素材 RiderSprites 复用，cell 5 = 200×130） / 2 小人×自行车（程序化绘制：转轮辐条 + 踏板 + 骑行动画）。仅塞尔达纹理表盘（faceId≤1）生效；程序化表盘仍走各自 motif。
- 布局几何：中央动画带 136..360（BAND），左右槽 y148 贴边（x 84/382），下方槽 y360，连接态 y420；槽位内容自适应尺寸，全部在圆屏安全半径内，不与秒针环（r=222）冲突。

## 自定义开机背景（bulk type 8）

- 新 bulk 通道 type 8：`'BGR' 1 w_le16 h_le16 + zlib(RGB565 LE)`，仅收 466×466 全屏图；解码进 PSRAM（≈434KB）。
- 固件**不持久化**背景——每次开机由 App 认证后（`CAP,BGR,1` 广播）自动重推；`#BGD` 或 w=h=0 清除包恢复 faceId 表盘背景。
- 接收成功即整页重绘（zbgRect 背景源切到自定义图，槽位文字照常叠加）。
- `CAP,BGR,1` 在认证后随其他能力一起广播。

其余与 musicA.16 一致：自适应旋转已移除、音乐封面、HID、吧唧 type 7 等不变。

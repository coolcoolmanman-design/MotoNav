# 固件 7.12.10-ui.2-zelda40.9-musicA.64

基线 musicA.63 / iOS 0.16.2.60（`aff3331`）。**固件小 Draft**（FO-210）；IPA 仍用 **0.16.2.60**（底图未改）。

## FO-210 · Infograph 实机「叠层灰轨 / 重影」

**根因**：叠层 `IG_SCALE` 用了 `1.14`，烘焙 BASE 实际 `DIAL_SCALE≈1.2469`。彩弧与子盘字画偏内，BASE 灰轨露在彩弧外侧 → 四角多余灰曲线，观感像底图多次叠画；子盘字也不落在铬框黑心中心。

**修复**：
1. `IG_SCALE` → `1.2469f`（与 BASE 一致）：色轨嵌回灰轨、子盘字回黑心、指针比例对齐
2. Infograph 缓存路径加固：无缓存时强制 `zbgRect` 擦净；子盘写字前垫黑心防残影
3. 保留 FO-208 切线字脚 + FO-209 触摸卡死修

## 建议实机验证

1. 升 FW musicA.64（IPA 仍 0.16.2.60）→ C Infograph；若底图已是 arcs-v6 可不重推
2. 四角灰轨应被彩弧盖住/嵌合，无外侧多余灰胶囊
3. 子盘字无重影；秒针走动无拖影；可划页不卡死

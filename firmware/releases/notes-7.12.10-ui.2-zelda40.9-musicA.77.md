# 固件 7.12.10-ui.2-zelda40.9-musicA.77

基线 musicA.76。配套 iOS **0.16.2.70（App 不变，无需侧载新 IPA）**。本版只改固件，release 保持 draft，不 publish。
修复上板后的两个实机问题：**① 封面背景显示成「下一张」而不是当前封；② 底栏左右两个播控太小、美观度不足**。

## 问题一：封面背景与中央卡错开一张

抓代码链路确认是**索引语义错位**，不是 App 下发问题：

- App 协议（`CoverQueueBridge.swift` / `DeviceContext.h`）明确：`slot 0 = 上一首`、`slot 1 = 当前封`、`slot 2 = 下一首候选`。
- 但固件 `cfDrawDeck()` 把卡位 `idx` 直接当槽号：`int slot = idx + cfShift`。静止（`phase=0, shift=0`）时**中央卡 `idx=0` 落到 `slot 0`（上一首）**，右侧第一张才是 `slot 1`（真·当前封）。
- 而背景 `mbgPickSrc()` 用的是 `coverImg`（type 5 当前封）或 `cfCovers[1]`。于是中央卡显示「上一首」、背景显示「当前封」，从屏幕上看起来就是「背景比中央卡多走了一张 / 是下一张」。

三条修复：

- **`cfDrawDeck()` 加 +1 偏移**：`slot = (idx + 1 + cfShift) mod 3`。静止时中央 = slot 1 当前封、左侧 = slot 0 上一首、右侧 = slot 2 下一首候选，三方语义终于对齐；`cfShift` 滚动方向不变（点下一首 → 中央临时变成 slot 2，手机重发队列后归零回到 slot 1）。
- **背景固定绑队列 slot 1**：`MusicBg.h` 新增 `mbgSrcSlot`，style 7 下**优先 `cfCovers[1]` 且优先于 type 5**，避免两条 bulk 到达顺序不同步时背景与中央卡再次错开。背景**刻意不跟随 `cfShift`**：吸附到下一首时不提前变成「下一张」的背景，只在手机重发队列（`parseCoverQueue()` 置 `musicBgDirty`）时重建。
- **诊断增强**：`musicBgBuild()` 日志改为 `[MBG] build mode=N src=WxH style=N slot=N`，实机可直接看出背景到底取了哪个槽。

## 问题二：底栏左右播控太小 / 不够美观

`cfChrome()` 原来左右键只是 **12×18px 裸三角 + 3px 竖条**，既没有圆底也没有边界；中间虽有 r19 实心圆，但三键散着放、缺层次。新增 `cfCtrlPill()` / `cfSkipIcon()` / `cfCtrlButtons()`：

- **淡玻璃胶囊**：`224×54` 圆角矩形（r27）把三键收成一组，逐像素 blend 到背景（约 20% 压暗，不盖住封面底），顶沿一道亮灰细高光，按 `chordHalf[]` 裁圆屏。
- **左右键放大到 r19 磨砂圆钮**：复用已验证的 `drawMusicGlassButton()`，外加 r20 亮灰外环；图标从「单三角 + 竖条」换成**竖条 + 双三角**的现代 skip 图标（`cfSkipIcon()`），在 r19 圆里不显空。
- **主播放键 r22**：白色外环 + 亮灰内环 + 上半圈柔和高光弧，播放/暂停图标不变。
- **按下态**：`musicPressed` 命中时对应键提亮（主键转纯白、侧键外环转白），热区完全不变（中间 r26 / 左右 52×52）。

只在整页 chrome 重绘时画，滑动帧仍走 318×220 局部脏矩形，帧率无回归。

## 其余不变

封面流几何（中央 164²@233,170 / 右 54×144@339 / 左 36×140@131）、逐列 16.16 梯形采样、倒影、卡带横拖 + ease-out 吸附、bulk type 12 协议字段、`#MS 0..7`、`#MBG 0..3`、iOS 侧全部不动。不新增 Flash 位图，新增缓冲都在 PSRAM（胶囊与圆钮直接画 framebuffer，零常驻内存）。

## 编译与体积

本地 `python firmware/build.py --cli ... --jobs 8`：**Flash 2,950,871 B（93%）/ RAM 145,468 B（44%）**，相对 musicA.76（2,950,231 B / 145,468 B）只增加 **640 B**，RAM 零增长，Flash 余量仍约 195 KB。

## 建议实机验证

1. 刷本版（板上已有 0.16.2.70），选「封面流 Cover Flow」：静止时**中央大卡与虚化背景应是同一张专辑**，左侧是上一首、右侧是另一张候选。
2. 切「封面背景」四档，日志 `[MBG] build mode=N src=64x64 style=7 slot=1`；背景跟着当前封变化，不再显示旁边那张。
3. 横拖切歌：吸附过程中背景保持当前封，手机重发队列后中央卡与背景一起换成新歌。
4. 底栏三键：左右为带外环的圆形按钮、明显比旧版大，按下有提亮反馈；点按命中区域与之前一致。
5. 切回主题 0..6、导航 / 屏保 / 动态背景 style 6/7 无回归。

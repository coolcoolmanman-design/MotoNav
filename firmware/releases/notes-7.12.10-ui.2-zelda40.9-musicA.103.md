# MotoNav 固件 musicA.103 · 全风格封面旋帧率 / 马赛克

> 配套 iOS **0.16.2.94**。基线 musicA.102（`cursor/dragonball-v3-minimap-blank-a025` @ `9a6f5f3`）。Draft-only。

## 根因（全屏转动封面 / 方案 B）

1. **旋帧过重**：`musicStyle==5` 每 36ms 全量 `fillScreen` + 旋封面 + scrim + 歌名/进度/胶囊，无 chrome 缓存 → 有效 FPS 掉、卡顿。
2. **马赛克**：`COVER_HI=256` 对 `MS5_FULL_R=226`（直径 452）最近邻放大 ≈1.77× → 块状。

## 本版改动

| 样式 | 是否转动 | 改动 |
|------|----------|------|
| 0 原版·冷雾银 | 播放慢旋圆封面 | `COVER_HI` 452（盘径 224 降采样，仍 NN 旋帧） |
| 1 封面轮播 | **不转**（静图邻封） | 无 |
| 2 柔光立体 | **不转** | 无 |
| 3 歌词主导 | 无连续旋 | 无 |
| 4 极简仪表 | 无连续旋 | 无 |
| 5 全屏转动封面 B | 满圆慢旋 | chrome 差分捕获 + 旋帧只画封面再 blit；`COVER_HI=452` scale≈1 |
| 6 黑胶唱片 | 中心封慢旋 | 保持 FO-219 局部旋帧；共享更大 `COVER_HI` |
| 7 封面流 Cover Flow | 拖/吸附透视动画 | 帧节流 40→36ms（≈28fps） |

协议仍 `COVER_PX=128`（无 bulk 变更）。旋帧不做双线性（musicA.5 课）。

## 刷机

1. 分区表 `0x8000` → app `0x10000` 刷 musicA.103
2. 装 IPA **0.16.2.94**
3. 圆屏设置 → 音乐控制 → 依次试 **全屏转动封面 / 原版·冷雾银 / 黑胶 / 封面流** 播放中的流畅度与清晰度

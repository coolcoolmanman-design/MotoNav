# Firmware v7.12.10-ui.2-zelda40.1 · 塞尔达40周年特别版 修订 1

基于 v7.12.10-ui.2-zelda40 的实机反馈修订版，版本号仍不占 ui 序列。

## 修订：开机动画

- **提速**：总时长 6.8s → 4.5s（亮度波淡入 3.8s → 2.3s，滚动流光 3.0s → 2.2s）
- **旗帜缩小**：前景构图整体缩至 0.836 倍，旗帜（含旗角）完整落在圆屏内，不再出界；
  缩小后四周由"同一构图压暗 + 虚化"的背景层补满，不露黑边
- 亮度波扩散半径随构图同步收紧（RMAX 340 → 276）

## 修订：待机页

- **在线场景**：动画恢复带从 140..348 收窄到 146..324——上沿不再擦掉大时钟底部，
  下沿不再擦掉 "ready" 状态文字；连接状态文字改为每拍重绘，彻底告别"被人物挡住/半截消失"
- **离线（no link）场景**：网格从 3px 缩到 2px（宽度 374px → 250px），场景带从 105..327
  收窄到 150..325——不再擦掉时钟下部；摩托底边位置不变
- 首次开机状态机未改动：未连接一定显示 no link 场景。若开机即显示 ready，
  是手机 App 在后台自动重连（系统级重连已绑定的 BLE 设备，连上即 ready）

## 刷机

- `app_0x10000.bin` 刷 0x10000（不擦 NVS，保留时钟/设置/配对）
- 完整包：`full_0x0.bin` 刷 0x0
